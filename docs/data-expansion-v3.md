# 기존 자료 추가 검수 — 2026-10-06

새로운 다운로드 없이 AI Hub 물류창고 후보 36장과 스마트 야드 안전모 후보 26장을 960×540 라벨 오버레이로 시각 검수했다. 전체 다운로드 자료의 검수가 완료된 것은 아니다.

## 결과

- PPE: 19장 승인, 7장 보류. 기존 53장과 합쳐 72장(학습 51 / 검증 12 / 개발 시험 9).
- 사람·지게차: 17장 승인, 19장 보류. 기존 31장과 합쳐 48장(학습 32 / 검증 7 / 개발 시험 9).
- P21: 오른쪽 작업자의 주황색 안전모 머리 라벨 추가.
- L11, L16, L22: 지게차 내부에 보이는 운전자 라벨 추가.
- L36: 빈 바닥에 잘못 붙은 사람 라벨 제거.
- 교정한 5장을 다시 오버레이로 확인했다. 가려진 머리, 흐릿한 운전자, 적재물을 지나치게 포함하는 박스 등은 이번 승인에서 제외했다.

## 보관 및 재현

출력은 `data/reviewed_pilot/expansion_v3/{ppe,logistics}`. 기존 데이터와 원본은 보존했다. `configs/review/expansion-v3-candidates.json`에 선별 원본과 ZIP 내부 경로를 기록했다. `scripts/prepare_reviewed_expansion.py`는 승인 목록과 교정 좌표를 적용하고 별도 사본을 만든다. 기존 출력이 있으면 덮어쓰지 않고 중단한다.

```bash
conda activate safety
python scripts/prepare_reviewed_expansion.py
```

각 모델 폴더의 `dataset.yaml`, `manifest.json`, `expansion-validation.json`과 상위 `review-decisions.json`으로 승인 여부·출처·교정·분할을 확인한다. 새 승인 이미지와 라벨의 SHA256도 기록했다.

전체 120장의 디코딩, 라벨 쌍, 클래스와 정규화 좌표 범위를 확인했다. 분할 간 동일 이미지 SHA256과 그룹 중복은 0이다. 물류창고는 기존 현장 분할을 유지했다. 같은 영상 그룹의 추가 프레임은 기존과 같은 분할에 들어간다. PPE 스마트 야드는 안전모 착용/미착용 파일 이름을 서로 다른 그룹으로 취급하지 않고 현장+촬영 날짜로 묶었다.

## 한계와 다음 작업

이번 개발 시험 자료도 시각 검수에 사용했으므로 완전히 독립적인 최종 시험이 아니다. 스마트 야드는 날짜가 달라도 같은 현장·작업자가 반복된다. 날짜 분할만으로 새로운 현장 일반화를 주장할 수 없다. 시연 영상 6개는 학습에 넣지 않았다.

여전히 작은 자료다. 추가 승인 36장이 곧 성능 개선을 의미하지 않는다. 다음에는 실제 높은 CCTV 시점, 원거리의 작은 사람·머리, 여러 사람이 함께 있는 장면을 더 확보하고 누락 라벨을 보완해야 한다. 이번에 승인한 스마트 야드 장면은 산업현장 다양성을 보충하지만 원거리 CCTV 부족을 해결하지 못한다. 재학습은 확대된 자료의 성능 변화와 기존 영상의 누락·오탐을 함께 비교한다.
