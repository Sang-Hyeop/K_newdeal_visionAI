# 보완 데이터 재학습 v9 결과

85장(train66/val8/test11), v6 초기 가중치, AdamW 학습률0.0001, 12epoch, 640 CPU로 학습 완료.

동일 개발 시험11장, conf0.25/IoU0.5: v6 사람TP12/FP5/FN6 → v9 TP8/FP3/FN10. 지게차TP10/FP2/FN1 → TP9/FP2/FN2. 사람 오탐이 줄었지만 누락이 증가해 기본 모델로 승격하지 않는다. 학습을 더 했다는 사실이 성능 향상을 보장하지 않는다.

전진·후진 각0/5/10/15/20초, 같은640/conf0.25 대표프레임으로 비교했다. 검출 개수는 정확도가 아니다. v9 전진10초는 사람과 지게차 모두 누락, 후진10초는 실제 지게차 누락과 설비의 지게차 오탐을 눈으로 확인했다. 전체 동영상 정답 평가나 연속 추적 평가는 수행하지 않았다. 시연 영상은 학습에서 제외했으나 개발 확인에 반복 사용했으므로 최종 독립 평가가 아니다.

모델은 models/pilot_v9_hard_examples/person_forklift.pt, experimental_not_promoted로 보관. 원본 모델은 유지했다. 코드·결과 기록은 로컬Git 체크포인트, 모델 포함7파일은 동일디스크SHA검증 복구 사본이며 외부백업이 아니다. 이번 단계 GitHub push/main 병합 없음.

다음 우선순위는 추가 epoch 반복이 아니라 학습 라벨 범위/누락과 사람 성능 퇴행을 검수하고, 검출 특징층을 유지하는 학습 전략을 별도 비교하는 것이다. 배경3장 추가만으로 산업설비 오탐 해결을 주장하지 않는다.
