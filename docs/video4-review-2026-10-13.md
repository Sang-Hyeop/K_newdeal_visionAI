# 4번 영상 리뷰 선택

outputs/diagnostics/video4_selected_lane_review_v4/video4/demo.mp4가 이번 사용자 리뷰용이다. 현재 보유 모델의 모든 조합이 최적임을 증명한 결과가 아니다. 기존 시연 전용 작업자/차량 조합은 설비 사람 오탐이 많아, 대표 장면에서 통로 작업자와 앉은 작업자를 관측하는 COCO1280 사람 경로를 이번 개발 리뷰에 선택했다. 지게차는 기존 학습된 v16+demo object 모델 후보, PPE는 선정한 최종v6 960을 사용한다. 새 학습 및 다른 카메라 변경 없음. PPE 사람 관측 입력과 구역 입력을 같은 검출로 통일했다.

중앙 노란선 사이의 기존 ROI 좌표와 최신 사용자 3초 규칙을 유지한다. 무차량 조건3초 미만SAFE/3초 이상최대WARNING; 차량관측시즉시WARNING/3초이상CRITICAL. 차량 관측 소실은 기존hold/UNKNOWN정책을 유지한다. 차량미검출은 실제부재증명이 아니다. 객체 이름과 통로 체류시간을 함께 표시하도록 렌더 연결을 보완했다. 92샘플 전체 새 추론,2/8/14/17초를 육안 확인. 통로 작업자 관측 체류가 이어지며3초이후WARNING. 설비 사람/차량 오탐 및 초기 사람 미탐, PPEUNKNOWN은 남아 있으며 사용자의 전체영상 리뷰가 다음 단계다. 배경 박스 숨김이나 시간표 강제 알림을 넣지 않았다.
