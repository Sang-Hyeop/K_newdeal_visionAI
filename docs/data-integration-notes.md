# 내려받은 데이터 통합 검토 (진행 중)

2026-10-06, 원본은 수정하지 않음. 학습은 아직 시작하지 않음.

## 확인된 데이터
- aihub_smartyard: JPG 56,570개, JSON 56,570개. 지게차/안전모 착용/미착용 폴더.
- aihub_logistics: JPG 19,023개, JSON 19,023개. JSON 스키마가 조선소와 다름.
- safe_unsafe_behaviours: 영상 691개. 이번 객체 검출용 이미지 정답 라벨은 찾지 못함.
- Downloads의 물류 데이터 ZIP은 압축 해제된 자료와의 중복 가능성이 있으므로 별도 합산하지 않음.

## 중요한 의미 차이
조선소 안전모 착용 클래스는 '안전모 착용머리'이며 표본 박스는 안전모와 머리를 포함한다. 우리 helmet(안전모 외곽만) 기준과 그대로 호환되지 않는다.
조선소 지게차 표본에서 보이는 사람이 미라벨 상태였다. PPE 표본에는 사람 몸체 라벨이 없었다. 이런 이미지를 4클래스 통합 모델에 그대로 넣지 않는다.

## 권장 진행
우선 사람·지게차 검출과 머리 착용상태 검출을 분리해 시험 학습할 수 있다. 이를 하나의 파이프라인에서 연결하면 최종 감지 모듈 목표와 양립한다.
단일 4클래스 모델을 유지하려면 보이는 사람·지게차·머리의 누락 라벨을 보완하고 착용머리 박스를 안전모 박스로 재라벨링해야 한다.
현재 클래스 설정은 아직 변경하지 않았다. 원본 클래스 수와 영상 그룹 중복 등 전수 검사가 끝난 뒤 구성을 결정한다.

## 물류 클래스 매핑 근거
AI-Hub 공식 데이터셋 510: WO-01 작업복 착용 작업자, WO-02 작업복 미착용 작업자 → person; WO-04 → forklift.
https://www.aihub.or.kr/aihubdata/data/view.do?currMenu=115&dataSetSn=510&topMenu=100
box coord는 표본상 x,y,width,height 형태이며 시각 검증 후 변환한다. 위험 상황 박스를 forklift로 대체하지 않는다.

## 검사 범위
현재 스크립트는 파일 구성, 클래스 빈도, 이미지 매칭, 조선소 XYXY 좌표 경계, 원본 그룹 중복을 확인한다.
전체 이미지 디코딩, 해시 중복, 물류 좌표 검증, 라벨 완전성은 후속 점검 대상이다.

## 1차 전수 구조 검사 결과
- 조선소: training 50,284 / validation 6,286 JSON. 사람 라벨은 4개뿐이므로 사람 검출 학습에 그대로 사용하지 않는다.
- 조선소: XYXY 박스가 없거나 형식이 다른 annotation 2,688개. 확인한 3개는 bbox=[]이고 polygon이 존재해 폴리곤 경계 박스로 변환 가능성이 있다. 전체 손상 라벨로 단정하지 않는다.
- 조선소: 파일명 마지막 프레임 토큰을 제외한 그룹 기준 train/validation 중복 2개. 원본 촬영 그룹 확인 후 재분리 필요.
- 물류: 압축 해제된 이미지 19,023개는 전부 validation. person 후보 WO-01 16,702 + WO-02 1,531 박스, forklift WO-04 12,212 박스.
- Downloads의 TL_07_지게차.zip에는 학습 JSON 94,238개가 있다. 압축 원천 이미지와 매칭·해제는 아직 하지 않았다.
- 구조 검사 결과는 outputs/data-audit/inventory.json에 저장했다. 디코딩·해시 중복·박스 시각 검수·사용 조건 확인은 아직 완료하지 않았다.

다음 실행 작업: 물류 학습 ZIP과 원천 이미지 ZIP을 페어링해 필요한 부분을 해제하고, person/forklift 박스 변환 표본을 검토한다. PPE는 착용머리/미착용머리 별도 모델 초안으로 데이터 정의를 맞추는 방안을 추천한다. 최종 4클래스 설정은 아직 변경하지 않는다.
