# 5번 영상 차량·탑승자 복구 리뷰 (2026-10-14)

상태: 현재 기본 실행에 통합됨. 현재 발표5 연결은 configs/team-runtime-index.json과 handoff.py를 따른다. 과거 출력은 정리에서 삭제했다. 이번 결과는 같은 CCTV의 보완 실험이며 미터 거리·독립 현장 정확도·실시간 처리 성능을 주장하지 않는다.

## 문제와 변경

지붕 없는 차량의 검출이 끊기고, 탑승자/장비/다른 보행자가 합쳐진 사람 박스가 보행자 규칙으로 들어갔다. 탑승자의 자기 차량 쌍만 제외하던 로직은 다른 차량과의 거리선도 만들었다.

- `VehicleRecovery`: 원본 프레임의 960 전체 화면 및 현재 사람·최근 차량 위치 주변 확대 영역을 다시 탐지한다. 기존 real_context_v2와 nvidia_object_adaptation_v1 가중치를 사용하며 신규 학습은 없다. 두 모델의 현재 차량 검출이 겹칠 때만 후보를 추가한다. 과거 위치는 탐색 영역에만 사용하며 누락된 차량의 박스를 만들어 표시하지 않는다.
- 보조 후보에만 최소 점수 .2/.25, 점수 기하평균 .3, 화면 높이의 .08 이상을 요구한다. 추가 후보에는 현재 사람 박스의 45% 이상 겹침과 차량 상부 위치 맥락도 요구해 사람 없는 적재물 오탐을 제한한다. 이는 역할 확정과는 별개이며, 탑승자를 관측하지 못하는 실제 차량도 복구하지 못할 수 있다. 기존 검출은 보존한다. 작은 먼 차량의 복구를 놓칠 수 있는 보수적 기준이다. 강한 모델의 현재 박스 기하를 선택하고 중복을 제거한다.
- `TemporalOperatorAssociation`: 3회 공간적 일관성으로 역할을 확인한다. 기존 보행자 증거가 있으면 차량과의 일치하는 움직임 2회도 요구한다. 짧은 ID 변경·누락은 연속성으로 연결하며 실제로 분리되거나 1초를 넘으면 해제한다. 탑승자 확인을 다시 3회 기다리는 중복 지연을 피하기 위해 현재 기본 경로에서 점유 상태 확인 횟수를 1로 한다. 역할 확인 3회 기준은 유지된다.
- 확인된 탑승자는 모든 보행자–차량 거리와 보행자 통로 이벤트에서 제외한다. 사람/PPE 관측은 유지한다. 역할 확인 대기는 미확인으로 기록하며 SAFE나 보행자 경고를 만들지 않는다.
- 차량과 별도 하단 보행자를 합친 큰 사람 박스, 같은 차량 내에서 수직 범위가 같은 포함 중복 박스를 기록 후 정리한다. 별도 하단 보행자는 보존한다. 휴리스틱으로 인한 가림 장면 오류 가능성이 남는다.
- 영상에는 확인된 탑승자에 `RIDER / NOT PEDESTRIAN`을 추가한다. 거리 기하는 앞선 bottom_center 실험을 유지한다.

## 실행

현재 실행 입구는 프로젝트 최상위에서 `python handoff.py run --video 5`입니다. 기본은 보관한 실제 관측 캐시를 사용합니다. `--fresh`를 추가하면 원본 추론→차량 복구→후보 검수→역할·거리 재평가를 순서대로 실행합니다. 내부 번호7은 발표5를 뜻하지만 사용자가 직접 지정하지 않습니다.

현재 실험의 초기 후보 일부는 사각형 확대 방식 pilot과 정사각형 확대 방식 양쪽의 실제 추론을 보존했다. 모든 시점에 같은 공간적 판정을 적용하며 특정 시각의 경고나 강제 클래스 변경은 없다. 원시 후보 로그·모델·원본·후처리 해시로 현재 결과를 보관한다. 새 실행의 후보 개수는 pilot을 재사용한 이번 결과와 다를 수 있다.

PPE 머리/몸 관측은 해시를 확인한 기존 실제 추론을 재사용한다. 차량 검출만 새 추론이며 추적·구역·근접·PPE 이벤트와 화면은 다시 생성한다. PPE 추론 성능 개선을 주장하지 않는다.

## 검증 및 한계

자동 검사는 차량 모델 간 일치, 누락 차량의 잔상 방지, 역할 대기/해제, 보행자의 일시적 겹침, ID 변경, 모든 차량 쌍의 탑승자 제외, 합쳐진 몸 박스 정리를 확인한다. 전체 영상 870샘플의 규칙 불변성과 문제 구간을 추가 확인한다. 검출 개수 증가나 경고 감소는 정답 기반 정확도 지표가 아니다.

- 최초 등장 시 역할 증거를 모으는 동안 거리 표시가 보류될 수 있다.
- 27초대처럼 실제 탑승자와 앞의 보행자가 겹치면 차량을 복구해도 탑승자 역할은 미확인일 수 있다.
- 바닥점은 영상 박스의 근사이며 실제 거리나 사각을 복원하지 못한다.
- CPU 확대 재탐지를 추가했으므로 실제 CCTV 실시간 운영 속도는 별도 측정이 필요하다.
- 평가 체크리스트 2/3/4/6/8에 해당: 모델 선택, 규칙, 연동, 오류 검증, 재현 기록.

## 2026-10-16 최종 선정과 현재 프레임 검수

현재 primary와 support 모델을 유지한다. 확대된 보완 데이터로 학습한 후보는 일부 사람 오탐을 줄였지만 29.375초 차량 박스가 옆 작업자·적재물까지 확대되어 거리 기준점이 악화됐다. 신규 후보를 활성 모델/리뷰에 반영하지 않았다. 비교와 한계는 `configs/review/forklift-current.json`에 통합한다.

회복 후보가 사람 전신 박스와 모호하게 겹치면 양 모델의 더 넓은 현재 이미지 재탐지로 확인한다. 두 모델 모두 지지하지 못하는 경우만 제외하며, 사람 겹침만으로 실제 차량을 제거하지 않는다. 과거 위치는 현재 이미지 검색에만 사용하고 박스를 생성하지 않는다. 새 회복 후보 검수는 최신 object_detections를 사용하고, 명시적인 `--verify-body-context`로 기존 확정 캐시를 재검수할 때만 movement 입력을 참조한다. 회복 단계는 두 입력 필드를 함께 갱신한다. 이 중간 캐시 이후 추적·이벤트·영상은 다시 계산해야 한다.
