# 7번 리뷰 요구와 공통 보완

## 사용자 확정 요구

- 손으로 그린 빨간 경계를 기준으로 적재 공간을 제외하고 사이 통로를 감시한다. 열린 선의 끝은 원래 바닥 경계를 참고해 닫았다. 제외 영역은 안전 판정이 아니라 통로 이벤트의 평가 제외다.
- 지게차와 보행자가 같은 통로 ROI에서 함께 관측되면 즉시 주의, 함께 관측된 시간이 3초가 되면 위험이다. 사람이 차량 등장 전에 머문 시간은 이 3초에 포함하지 않는다. 관측 공백 시간도 더하지 않는다.
- 근접 거리는 ROI와 별도로 전체 화면의 보행자 발밑에서 차량 박스의 가까운 경계까지 계산한다. 사람 높이 기준으로 정규화한 화면상 거리이며 미터가 아니다. 근접 위험은 체류 3초를 기다리지 않는다.
- 탑승자는 자기 차량과의 근접 이벤트·연결선 및 보행자 통로 체류에서 제외한다. PERSON·PPE 관측은 유지한다. 다른 차량과의 근접은 별도다.
- 차량 미탐(시작, 후진 등장, 지붕 없는 운반장비), 차량이 사라지고 PERSON만 남는 현상을 전체 영상에서 개선한다. 특정 시각에 박스나 경고를 삽입하지 않는다.

## 원인과 구현

0.42초 차량은 CVAT 신뢰도 0.82, 16초 후진 차량은 0.52로 실제 모델 검출이 있었으나 v16 모델 동의가 없어 후처리에서 삭제됐다. 이전 교차 확인 모델을 NVIDIA 모델로 바꾸고 전체 화면 및 관측된 객체 주변 확대에서도 교차 확인한다. 낮은 차량 점수는 보조 모델의 현재 관측이 있을 때만 허용한다. 사람 검출만으로 차량 박스를 만들지 않는다. 팔레트·작업자를 차량으로 잡는 반례도 확인한다.

근접은 공통 box_boundary 계산을 사용한다. 탑승자 판별은 포함 정도·상대 크기 및 최근 보행자 관측을 이용한 카메라 내 추정이다. 최근 바깥에서 관측된 보행자를 박스가 덮었다는 이유만으로 탑승자로 제외하지 않는다. 역할 추정에 의한 누락 위험은 남으므로 결과 리뷰가 필요하다.

ROI는 요청한 저장 공간 제외 좌표로 갱신했다. 통로 공동 관측 시간과 무차량 체류 시간은 별도다. 무차량은 3초 전 정상, 3초부터 최대 주의이며 미검출을 부재 확정으로 표현하지 않는다. 차량 관측 소실은 기존 UNKNOWN 처리한다. 이동 위험 표시는 통로·근접의 높은 위험도를 취하고 PPE는 별도 표시한다. 옅은 ROI 채움, 중복 구역 배너 제거, 주의·위험 근접 연결선으로 화면을 정리한다. 안전 거리와 미확인 근거는 이벤트 로그에 유지한다.
