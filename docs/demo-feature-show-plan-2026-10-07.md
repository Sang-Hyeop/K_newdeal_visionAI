# 현재 발표 영상 1~5 — 사용자 확정 시연 기준

원본 파일명·JSON의 video_number·발표 번호는 모두 1~5번으로 같습니다. 2번은 별도 실행기를 사용합니다. 실행은 `python handoff.py run --video N`을 사용합니다. 이 문서는 기존 파일명을 유지하면서 현재 기준으로 통합했습니다.

## 공통

2026-10-15 사용자 확정: 1번은 사람·지게차 근접만, 2번은 사람 탐지 기반 ROI 침범과 안전모 PPE, 3번은 사람 탐지 기반 안전모 PPE만, 4번은 사람 탐지 기반 체류시간만, 5번은 네 기능 모두 표시합니다. 제외 기능의 이벤트도 저장하지 않습니다. SAFE=해당 규칙상 안전, WARNING=주의, CRITICAL=위험, 근거 부족=미확인입니다. 대상 미관측을 안전이나 실제 부재로 단정하지 않습니다. 실제 미터 거리를 제공하지 않습니다. 특정 영상 시각에 맞춘 경고를 넣지 않습니다.

## 1번 — 지게차·작업자 충돌 위험

원본 `1_forklift_worker_collision_risk.mp4`. 고정 ROI로 사람–지게차 근접을 제한하지 않고 화면상 거리로 판단합니다. 카메라 설정은 `configs/cameras/reverse-proximity.json`, 객체 검수는 `configs/video1-object-review.json`입니다. 사용자가 확인한 설비/박스 오탐 보완을 적용하고 PPE는 실행·표시·기록에서 제외합니다.

## 2번 — 위험구역 ROI 침범

원본 `2_restricted_zone_intrusion.mp4`. 빨간 바닥 기준 ROI를 사용하며 현재 사람 박스 밑면 중앙이 들어가면 즉시 CRITICAL, 경계 인근은 WARNING입니다. 체류시간 조건과 분리하며, 예외적으로 안전모 PPE와 사람 탐지를 함께 유지합니다. `configs/cameras/robot-intrusion.json`이 좌표·진입 기준이며 좌표 상태는 해당 설정에 기록된 수동 초안입니다. AI 생성 시연 영상이므로 실제 CCTV 일반화 평가가 아닙니다.

## 3번 — 안전모 착용/미착용

원본 `3_PPE_Helmet.mp4`. 지게차 탐지와 다른 위험 기능을 제외하고 사람과 머리를 연결해 착용/미착용 후보·판정 중·판정 불가를 표시합니다. 미검출만으로 미착용을 만들지 않습니다. 후드가 안전모가 아님을 확인할 수 있으면 현재 라벨 정책의 미착용 머리에 포함하되, 흐림·가림으로 분류할 수 없으면 보류합니다. `configs/cameras/ppe-warehouse-review.json` 및 `configs/ppe-user-approved-policy-2026-10-15.json`을 사용합니다.

## 4번 — 통로 체류

원본 `4_hazard_zone_dwell.mp4`. 왼쪽 기계 작업영역과 오른쪽 보행로는 허용구역이며 노란선 사이 통로를 감시합니다. `configs/cameras/dwell-demo.json`이 기준입니다. 화면과 이벤트에는 사람 및 체류시간만 남기고 PPE·침범 기능은 제외합니다. 기존 차량 관측에 따른 체류 판정 조건은 내부적으로 유지합니다.

- 차량이 관측되지 않는 통로 체류: 3초 미만 정상, 3초 이상 최대 WARNING.
- 같은 통로에 차량이 관측되는 조건: 진입 즉시 WARNING, 조건부 체류 3초 이상 CRITICAL. 과거 유차량 5초 기준은 폐기됐습니다.
- 차량 관측 소실은 부재 증명이 아니며 미확인 정책과 마지막 관측 경과시간을 적용합니다.
- 체류시간을 표시합니다. 빈 설비 참고 이미지와 현재 프레임을 대조해 기계 오탐을 제외하되, 이동 작업자를 무조건 고정 영역으로 지우지 않습니다. 이는 카메라별 보완이며 일반화 모델 개선이 아닙니다.

## 5번 — 물류창고 통합

원본 `5_Logistics Warehouse.mp4`. `configs/cameras/warehouse-summary.json`의 감시 바닥에서 적재 안전구역을 제외합니다. 보행자·차량 공동 관측 시 즉시 WARNING, 공동 관측 3초부터 CRITICAL입니다. 미관측·가림은 별도 미확인으로 남깁니다.

근접은 현재 발표에서 밑면 중앙 기준 상대 거리 실험을 사용합니다. 탑승 역할이 확인된 사람은 모든 보행자–차량 근접과 보행자 통로 판정에서 제외합니다. 역할 대기에는 거리·통로 경고를 만들지 않습니다. 최초 등장·탑승자 가림 시 거리선이 보류될 수 있습니다. 차량 복구·탑승자 시간적 연관은 [현재 상세 설명](video5-vehicle-rider-recovery-2026-10-14.md)을 따릅니다.

근접·ROI 침범·체류시간·안전모 PPE를 모두 표시합니다. ROI는 현재 설정의 좌표·색·알파를 사용합니다. 4번 ROI/투명도를 5번에 그대로 복사하지 않습니다. 거리는 full-frame 관측으로 계산하되 알림·표시에는 카메라별 통로 필터와 탑승자 확인 정책이 적용됩니다. 5번의 밑면 중앙·차량 복구는 실험적 경로이며 실제 거리·실시간 운영 정확도를 보장하지 않습니다.

## 현재 파일과 검증

최신 확정 영상은 `outputs/reviews/`의 5개이며 이벤트는 `outputs/events/presentation1`~`presentation5`입니다. 모델6개와 실제 연결은 `configs/team-runtime-index.json`이 기준입니다. 원본별 전체 리뷰와 개발 영상에서 확인한 결과를 독립 현장 정확도로 설명하지 않습니다.
