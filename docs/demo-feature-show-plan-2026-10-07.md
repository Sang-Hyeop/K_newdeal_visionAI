## 1. 왜 이 문서가 필요한가

- 시연은 **기능별 영상에 나눠 보여준다**. 한 영상으로 전부 증명하지 않는다.
- 다만 사용자는 **안전모(PPE)만은 1~7 전부**에서 켠다고 재확정했다. (예전 “PPE는 5·6만”과 다름)
- 근접(사람–지게차, 지게차–지게차)과 구역 ROI 침범을 **섞어 설명하면 안 된다**.
- 미탐을 안전으로 말하거나, 미터(m)를 만들어 내면 안 된다.

이 문서를 바꾸려면 **사용자가 영상 번호 말로 다시 확정**한 뒤에만 수정한다.

## 2. 공통 규칙 (영상 1~7 전부) — 확정

1. **PPE(안전모 / 미착용 후보)는 1~7번 모든 시연 영상에서 항상 켠다.**
2. 각 영상은 **그 영상이 보여 줄 핵심 기능**을 강조한다. 없는 기능을 “된다”고 꾸미지 않는다.
3. **거리 단위는 기본 화면상 거리.** `distance_meters`는 보정 없으면 `null`. 다만 **3번 지게차–지게차**는 m가 가능하면 쓰고, 힘들면 화면상 거리.
4. **미탐 ≠ 안전.** 사람·지게차·머리가 안 보이거나 불확실하면 `SAFE`가 아니라 **`UNKNOWN`(미확인)**.
5. 기능별 `SAFE`는 **그 기능·그 대상**의 규칙 결과이지, **현장 전체 안전이 아니다**.
6. **기능 배너는 동시에 띄운다.** (예: 근접 WARNING + PPE UNKNOWN을 같이 표시, 서로 덮지 않음)
7. 특정 초 단위 시간표에 맞춘 가짜 알림을 구현·설명하지 않는다.
8. PPE **착용 / 미착용**은 구분해서 보여 준다. (5·6번 특히, 전 영상 PPE ON이므로 가능하면 동일)


### 심각도 말투 (UI·발표 통일)

| 내부 코드 | 보여줄 말 | 의미 |
|---|---|---|
| `SAFE` | 안전 | 해당 기능 규칙상 위험 아님 (전체 현장 안전 아님) |
| `WARNING` | 주의 | 해당 기능 규칙상 주의 |
| `CRITICAL` | 위험 | 해당 기능 규칙상 위험 |
| `null` / 관측 미확인 | 미확인 | 증거 부족·가림·미탐. **안전으로 말하지 않음** |


### ROI 오버레이 색 (4·7번 고정 ROI 공통)

통로/안전지대 **고정 ROI 다각형**을 반투명으로 칠한다. 상태별로 **색만** 바꾸고, fill 알파는 **0.15~0.2** 정도로 매우 흐리게 두어 원본이 잘 보이게 한다.

| 상태 | 색 | 투명도 (알파) | 비고 |
|---|---|---|---|
| 안전 (SAFE / 정상 구간) | **초록** | **약 0.15~0.2** (매우 흐리게) | 눈에 띄되 원본이 잘 보임 |
| 주의 (WARNING) | **주황** | **약 0.15~0.2** (반투명) | 안전과 동일 대역의 흐린 채우기 |
| 위험 (CRITICAL) | **빨강** | **약 0.15~0.2** (반투명) | 색만 바꾸고 가림은 최소 |
| 미확인 | (선택) 회색 또는 테두리만 | 약 0.15~0.2 | 안전으로 칠하지 않음 |

채우기(fill) 기준 알파 **0.15~0.2**. 테두리는 조금 더 진해도 됨.

적용 영상: **4번, 7번** (고정 ROI가 있는 시연). 1·2·3·5·6은 고정 ROI 강조 오버레이를 쓰지 않음.

### 4.3 영상 3 — `3_forklift_crush.mp4` — **시연 규칙 확정 / 구현 후속**

| 항목 | 내용 |
|---|---|
| 장면 | 지게차끼리의 충돌·접근을 보여 주는 영상 |
| 핵심 판정 | **ROI 침범이 아님.** **지게차와 지게차 사이 화면상 거리**로 안전 / 주의 / 위험 |
| 지게차 | **무조건 검출** (이 기능의 전제. 두 대 관측이 필요) |
| 사람 | 감지할 수 있으면 하고, 확인 못하면 **미확인** |
| 안전모 | 감지할 수 있으면 하고, 확인 못하면 **미확인** |
| 거리 | **가능하면 m**, 불가 시 화면상 거리 |

**발표용 한 줄**  
> 3번: 구역 ROI가 아니라 지게차–지게차 화면상 거리로 안전·주의·위험을 봅니다. 지게차는 필수, 사람·안전모는 보이면 표시하고 못 보면 미확인입니다.

**구현 방침 (사용자 확정)**  
- **반드시 구현한다.** 3번 영상이 존재하는 이유가 이 기능이다. 고정 ROI가 아니라 **지게차–지게차 거리**.  
- 거리: **m(미터)가 가능하면 m**, 카메라 보정/기준길이 확보가 힘들면 **화면상 거리**로 계산 (그때 `distance_meters=null` 또는 미제공을 명시).  
- 현재 코드는 `person_forklift_proximity`만 있음 → `forklift_forklift_proximity`(가칭) **신규 구현 과제**.  
- 구현 전에는 “이미 된다”고 말하지 말고, 구현 후 시연.

### 4.4 영상 4 — `4_hazard_zone_dwell.mp4` — **확정**

| 항목 | 내용 |
|---|---|
| 목적 | **위험구역(통로) 침범**과 **체류**를 보여 주는 영상 |
| 판정 방식 | 1·2·3번의 화면상 거리 근접이 **아님**. **고정 ROI(노란선 사이 통로)** 사용 |
| 허용(사람이 있어도 괜찮은 곳) | ① **왼쪽 작업공간** ② **오른쪽 노란선 바깥 초록색** 보행 쪽 |
| 침범 | **노란선과 노란선 사이 중심길** = 지게차 통로. 사람이 다니면 **침범** |
| 체류 시간 | **화면에 숫자 표시** |
| 통로 + **지게차 없음** | 체류 **3초 미만 → 정상(SAFE)**. **3초 이상 → 주의(WARNING)까지만** (위험으로 안 올림) |
| 통로 + **지게차 있음** | 진입 **즉시 주의(WARNING)**. 체류 **5초 이상 → 위험(CRITICAL)** |
| ROI 오버레이 | 초록/주황/빨강 fill 알파 **0.15~0.2** (7번과 동일) |
| 사람·지게차 외 물체 | 시연에서는 **말하지 않거나 “추후” 한 줄**. 현재 클래스 없음 — 있는 척 금지 |
| 영상에서 지게차가 잘 안 보여도 | 규칙은 유지. 미검출은 부재 증명 아님(hold/미확인 정책은 구현 시 Codex hold 참고 가능) |
| PPE | **ON**. 확인 어려우면 **미확인** (안전으로 단정 X) |
| 출입금지 문구 | 법적 출입금지 확정이 아님. **시연용 통로 규칙** |
| ROI 오버레이 | 안전=초록 / 주의=주황 / 위험=빨강, fill 알파 **0.15~0.2** |

**발표용 한 줄**  
> 4번: 왼쪽 작업·오른쪽 초록은 허용, 노란선 사이는 지게차 통로. 무차량: 3초 미만 정상·3초 이상 주의. 유차량: 진입 즉시 주의·5초 이상 위험. 체류 숫자·ROI 알파 0.15~0.2. 안전모도 보고 어려우면 미확인.

**Codex와 맞춤**  
- 이미 구현: `vehicle_lane_conditional_v1` (`docs/checkpoints/2026-10-07/vehicle-lane-v1.json`, `docs/detection-goal.md` 통로 절)  
- ROI id 예: `yellow_line_vehicle_lane`  
- 실행: `scripts/run_zone_dwell_video.py` + `configs/cameras/dwell-demo.json`  
- 심각도 수치는 **7번과 동일**: 무차량 <3s 정상·≥3s 주의 / 유차량 즉시 주의·≥5s 위험. (예전 Codex lane의 “무차량이면 즉시 WARNING·유차량이면 즉시 CRITICAL”보다 **완화·세분화**된 시연 규칙.) 물체는 시연 비표시/추후.

- 오늘 규칙도 PPE·사람이 메인. 여기에 **먼 지게차 best-effort**와 **ROI 없음**을 시연 문장으로 확정.

### 4.6 영상 6 — `6_Helmet_forklift.mp4` — **확정**

| 항목 | 내용 |
|---|---|
| 장면 | **여러 명**의 작업자 + (짤린) 지게차 앞부분 |
| 반드시 | ① **사람 검출** ② **안전모(PPE)** — **착용한 사람**과 **안 쓴(맨머리) 사람**을 구분해 보여 줌 |
| 권장(best-effort) | 화면이 **짤린 지게차 앞부분**도 잡을 수 있으면 검출. 못 잡으면 **미확인** |
| 고정 ROI | **없음** |
| 근접/통로 | 이 영상의 핵심 시연 축 아님 |
| PPE 미확인 | 머리/모자 확인 어려우면 미착용으로 단정하지 않고 **미확인** |

**발표용 한 줄**  
> 6번: 여러 작업자의 사람과 안전모(착용/미착용)를 봅니다. 잘린 지게차 앞부분은 보이면 잡고, 못 보면 미확인입니다. ROI는 없습니다.

**Codex와 맞춤**  
- Codex PPE 검증에 6번도 사용. 오늘 규칙에 **착용 vs 미착용 구분 강조** + **부분 지게차 best-effort** + **ROI 없음**을 명시.

### 4.7 영상 7 — `7_Logistics Warehouse.mp4` — **확정 (종합 시연)**

| 항목 | 내용 |
|---|---|
| 역할 | **1~6에서 보여 준 기능들이 들어가는 종합 영상** (물류창고). 한 영상으로 “전부 완벽 증명”이 아니라 **통합 시연** |
| 검출 대상 | **사람, 지게차, 안전모(PPE)만**. 그 외 일반 물체 클래스는 이 영상에서도 시연하지 않음 |
| 미탐 | 못 잡으면 **미확인** (안전 아님) |
| 고정 ROI | **있음** (4번과 구역 정의가 다름 — 아래) |

**ROI / 공간 규칙 (7번 전용)**  
- **안전지대(사람이 머물러도 되는 곳):** 물건이 적재된 바닥의 **노란색 박스 안**  
- **지게차 이동 통로:** 그 **바깥** 공간  
- 사람이 지게차 통로에 들어오면 **침범**으로 잡는다.

**통로 침범·체류 심각도 (7번 — 4번과 다름)**  

| 상황 | 판정 |
|---|---|
| 통로 진입 + **지게차 없음** | 체류 **3초 미만 → 정상(SAFE)**. **3초 이상 → 주의(WARNING)까지만** (위험으로 안 올림) |
| 통로 진입 + **지게차 있음** | 진입 **즉시 주의(WARNING)**. 체류 **5초 이상 → 위험(CRITICAL)** |
| 체류 시간 | **화면에 숫자 표시** |
| ROI 오버레이 | 초록/주황/빨강 fill 알파 **0.15~0.2** |

**근접 거리 (7번 조건부)**  
- **지게차가 그 공간에 있고 작업자가 통로에 들어왔을 때만** 사람–지게차 **화면상 거리**(또는 보정 되면 m)도 계산·표시.  
- 지게차 없을 때의 단순 통로 체류에는 근접 거리를 메인으로 돌리지 않음.

**PPE**  
- ON. 착용/미착용 구분. 확인 어려우면 미확인.

**4번과의 차이 (혼동 금지)**  

| | 4번 | 7번 |
|---|---|---|
| ROI 의미 | 노란**선 사이**=지게차 통로 / 왼작업·오른초록=허용 | 노란 **박스 안**=사람 안전지대 / **바깥**=지게차 통로 |
| 무차량 | **3초 미만 정상 · 3초 이상 주의** (위험 캡) | **동일** |
| 유차량 | **진입 즉시 주의 · 5초 이상 위험** | **동일** |
| ROI 오버레이 | 초록/주황/빨강 알파 **0.15~0.2** | **동일** |
| 근접 거리 | 강조 안 함 | **유차량+통로 침범 시에만** 계산 |

**ROI 오버레이**  
> 상태별 반투명: 안전 초록(매우 흐림) · 주의 주황 · 위험 빨강. (위 「ROI 오버레이 색」 절과 동일)

**발표용 한 줄**  
> 7번: 물류창고 종합 시연. 사람·지게차·안전모만. 노란 박스 안=안전지대, 밖=통로. 무차량: 3초 미만 정상·3초 이상 주의. 유차량: 진입 즉시 주의·5초 이상 위험. 유차량일 때 사람–지게차 거리도. ROI는 초록/주황/빨강 알파 0.15~0.2.

**구현 메모**  
- 현재 Codex `dwell-demo` / `yellow_line_vehicle_lane`은 **4번 기하·정책** 기준.  
- 7번은 **별도 카메라 설정**(노란 박스 폴리곤 + 7번 심각도 표)이 필요.  
- “기능 전부” = 검출(사람/지게차/PPE) + ROI 침범/체류 + 조건부 근접. 3번의 지게차–지게차 근접을 7번에 반드시 넣으라는 뜻은 아님(필요 시 별도 명시).

## 9. 다른 AI에게 줄 프롬프트 (복붙용 · 완전 유지)
