# 체류시간 상태 계산 모듈

`src/zone_dwell.py`의 `ZoneDwell`은 영상 시간, 추적 ID, 작업자 박스와 ROI를 받아 체류 상태를 계산한다. YOLO 검출과 추적기는 아직 연결하지 않았다. 추가 체류 영상에서 위험 알림이 검증됐다는 뜻은 아니다.

- 작업자 박스 하단 중앙이 ROI 안 또는 경계에 있으면 구역 내부로 취급한다.
- 3초 이하는 SAFE, 3초 초과 8초 미만은 WARNING, 8초 이상은 CRITICAL.
- 시간은 실행 PC의 시간이 아니라 원본 영상 timestamp를 사용한다.
- 감지 누락 시 severity=null, observation_status=unconfirmed. 관측되지 않은 시간은 더하지 않는다.
- 짧은 누락 동안은 누적 관측 시간을 유지하지만 누락 전후의 공백은 제외한다. `observed_dwell_seconds`는 완전한 연속 체류시간의 증명이 아니라 보수적인 관측 누적 시간이다.
- 마지막 관측 이후 max_gap_seconds(기본 1초)를 초과하면 이전 체류를 폐기한다. 다음 검출에서 새 방문을 시작한다.
- 실제로 구역 밖에서 관측되면 해당 방문을 초기화한다. SAFE는 그 작업자의 구역 체류 상태일 뿐 전체 현장 안전 판정이 아니다.
- 장면 전환, ROI 변경, 추적 ID 초기화 시 reset()을 호출한다. 미검출 동안 다른 사람에게 같은 ID가 재사용되는 문제는 추적기 측에서 방지해야 한다.
- 각 입력 프레임의 시각은 엄격히 증가해야 한다. 추적 샘플 간격이 1초를 넘는 경우 기본 max_gap과 맞지 않으므로 설정을 조정해야 한다.

`python -m unittest discover -s tests -v`로 3·8초 경계, 이탈 후 재진입, 누락 시 미확인·시간 제외, 장기 누락, 여러 ID 분리, 시간 역행 거부와 초기화를 검사했다. 실제 추적 품질·ROI 위치·가림에 대한 영상 검증은 별도 단계다.
