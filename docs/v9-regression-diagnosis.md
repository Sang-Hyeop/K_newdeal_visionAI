# v9 퇴행 진단

동일시험11장의29개 정답 객체를 v6/v9에서 개별 대조했다. v6에서 맞추고 v9에서0.25 기준 아래로 떨어진 사람4개와 지게차1개를 찾았다. 새로 회복한 정답은 없다. 네 사람의 v6→v9 신뢰도는0.265→0.237,0.322→0.089,0.670→0.159,0.328→0.198이다. IoU0.5를 넘는 저신뢰도 박스는 존재했다. 이는 관측된 실패 형태이며 훈련 퇴행의 인과적 원인까지 입증한 것은 아니다.

검증8장에서 v9 신뢰도0.25: 사람TP5/FP3/FN5, 지게차TP7/FP5/FN1. 기준0.10: 사람TP5/FP9/FN5, 지게차TP7/FP9/FN1. 기준을 낮춰도 이 검증 표본의 누락은 줄지 않고 오탐만 늘었다. 운영 임계값은 변경하지 않았다. 시험에 맞춘 기준 선택은 하지 않았다.

train66장 라벨 구조 집계: 사람108박스/지게차58박스/배경3장. 사람 높이 정규화값×640의 대용값에서32미만5개,64미만29개. 실제 letterbox 픽셀 크기가 아니며 작은/가린 사람의 원인 비율을 입증하지 않는다. 기존 추가 CCTV10장 및 직전 신규 전체화면6장은 시각적으로 다시 확인했다. CCTV에는 몸 일부만 보이는 사람과 선언된 검은 마스크4장이 있으며 가림/부분신체 라벨 정책을 일관되게 관리해야 한다. 이번에 명백한 누락 라벨 오류를 확정하거나 라벨을 수정하지는 않았다. 전체66장의 전수 수동재검수가 끝난 것은 아니다. 시험의 퇴행 장면 중 운전석 사람/작업자를 확인했고 held-out 라벨은 수정하지 않았다.

다음 통제 실험: v6 초기 모델, 동일85장·640·학습률0.0001·12epoch를 유지하고 backbone앞10층 freeze만 바꾸어 v9와 비교한다. 모든 특징/사람분류층을 고정하는 실험이 아니며 성능 회복을 보장하지 않는다. 기존v8은80클래스 초기화/다른데이터/학습률이라 이 비교의 대체 결과가 아니다. 재학습을 아직 시작하지 않았다.

실행: safety에서 `python scripts/diagnose_v9_regression.py`. 진단JSON 및 검증 임계값별 수치, 퇴행 장면GT 오버레이를 남긴다. 지표는 작은 개발자료 진단이며 최종 독립현장 평가가 아니다. 이번 저장은 로컬Git이며 GitHub push/main병합 없음.
