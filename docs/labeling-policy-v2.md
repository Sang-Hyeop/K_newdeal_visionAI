# 라벨링 기준 v2 — 학습 표본 검수

v1의 helmet(안전모 외곽)과 현재 데이터의 착용머리 박스는 다르다. 원본 데이터를 활용하는 PPE 시험 모델은 helmeted_head(안전모 포함 머리 전체) / no_helmet_head로 정의한다. 보이는 머리·얼굴을 감싸며 몸통을 포함하지 않는다. 모자/후드는 안전모가 아닌 것으로 확인될 때 미착용 머리에 포함한다. 가림·작은 크기로 불분명하면 보류한다.

시험 구성은 두 검출 모델이다: person/forklift와 helmeted_head/no_helmet_head. 후처리에서 사람과 머리를 연결한다. 통합 4클래스 모델은 전 클래스 누락 라벨을 보완한 이후 별도로 평가한다. detection-classes.yaml과 과거 v1 수동 예시는 역사적 초안이며 현재 학습 설정으로 사용하지 않는다.

박스는 보이는 객체를 감싼다. 운전자도 person으로 라벨링한다. 지게차의 별도 화물은 제외한다. 데이터 원본 박스가 이 정의와 다른 경우 수정을 검토한다. 기존 원본 클래스를 무조건 같은 의미로 매핑하지 않는다.

## 이번 검수
- 물류: 12개 raw_video_ID에서 1장씩 추출. person 18 / forklift 12. 원천 이미지 해상도로 XYWH를 XYXY와 YOLO 정규화 형식으로 변환. 원본 JSON·ZIP member·raw_video_ID를 manifest에 보존.
- 물류 표본은 운전자 비중이 높다. 실제 사람–지게차 접근 학습을 위해 보행자 동시 등장, 빈 장면, 일반 박스/장비 배경을 추가해야 한다. 이 12장만으로 학습하지 않는다.
- PPE: 원본 train의 12장 라벨을 시각 검토. P05는 명확한 착용머리 여러 개가 누락되고 회전/타일 형태가 보여 보류. P11은 뒤쪽 미착용 머리 1개를 별도 수정 초안으로 추가. 원본은 변경하지 않음.
- 일부 표본은 작은/가린 머리가 있어 전체 해상도 재검수 필요. 표본만 보고 나머지 이미지의 품질을 추정하지 않는다.
- 모든 표본은 training_eligible=false. 시연 영상 6개는 학습에 포함하지 않음.

## 다음 실행 단계
1. PPE 382장의 같은 원본 증강 그룹을 묶어 누락 라벨/비정상 변형을 검수하고 수정/제외 기록 작성.
2. 물류 라벨에서 원본 촬영·현장 그룹별 클래스 구성을 집계해 보행자와 운전자, 다양한 거리·배경을 포함하는 학습셋 선정.
3. 원천 그룹 중복 없이 train/val/test 구성, 정상 샘플·배경 포함, 정답 박스 완전성 확인 후 소규모 시험 학습.
