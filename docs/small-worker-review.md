# 작은 작업자 추가 검수

2026-10-06, 기존 물류창고 전체 색인에서 이전 검수와 겹치지 않는 원본 영상 그룹을 우선 골랐다. 라벨상 가장 큰 사람의 높이가 원본에서 60~200픽셀인 후보를 사용했고, 현장별 최대 2장과 기존 현장 분할을 유지했다. 이 조건은 높은 CCTV 시점을 보장하지 않으며 실제 장면을 확인해야 한다.

후보 16장을 960×540 오버레이로 확인해 10장을 승인하고 6장을 보류했다. S06은 지게차 박스 상단을 마스트까지 확장했다. S03은 최초 교정 검토 후 적재물 뒤에 사람이 부분적으로 보이는 것을 확인해 승인에서 제외했다. 가려진 객체의 라벨 완전성이 불확실하면 삭제로 해결하지 않는다.

최종 객체 데이터는 `data/reviewed_pilot/logistics_v4`에 58장(학습 39 / 검증 8 / 개발 시험 11), 사람 90개와 지게차 59개 박스를 포함한다. 원본과 이전 데이터 버전은 보존했다. 재현 스크립트는 `select_small_worker_review.py`, `prepare_small_worker_expansion.py`이며 기존 출력 덮어쓰기를 차단한다. 후보·출처는 `configs/review/small-workers-v1.json`, 승인과 교정 내역은 출력 manifest에 기록한다.

선별 중 디코딩/해상도 불일치로 94개 후보 행을 보류했다. 이는 전체 데이터의 오류 개수가 아니라 이번 선별 경로에서 만난 행 수이며, 같은 원본 그룹의 인접 프레임이 포함될 수 있다. 좌표를 임의로 재조정하지 않았다. 최초 탐색 중단 폴더 `data/training_review/expansion_v4`는 학습셋이 아니다.

PPE는 이번 단계에서 추가하지 않아 기존 72장을 유지한다. 모든 승인 이미지와 라벨을 읽고 형식·범위를 검사했으며 물류 현장/영상 그룹과 동일 이미지 SHA256의 분할 간 중복은 없다. 이 작은 개발 시험 데이터로 최종 성능을 주장하지 않는다.

## 시연 영상 목록

`configs/demo-videos.json`에 현재 이름, FPS, 프레임 수, 해상도, SHA256과 학습 제외 상태를 등록했다. 영상은 총 7개이며 이름에 순서 번호가 붙었다. 이전 출력의 파일명과 현재 파일명이 다를 수 있다.

추가된 `4_hazard_zone_dwell.mp4`는 1920×1080, 약 19.06초, 457프레임이다. 0·8·12초 표본에서 설비 앞 작업자와 통로 보행자를 확인했다. 명확한 위험구역 경계나 8초 이상의 실제 구역 체류는 아직 검증되지 않았다. 별도 ROI 설정과 동일 인물 추적을 적용한 후 사용 적합성을 확인한다. 영상 전체 길이가 19초라는 사실만으로 8초 체류 사례가 있다고 판단하지 않는다.

## 재학습과 동일 조건 비교

객체 모델은 YOLO26n 사전학습 가중치에서 30epoch 재학습했다. 실행 결과는 `outputs/training/logistics_pilot_v4`에 보관했다. 입력 데이터 SHA256 스냅샷과 test_metrics.json, fixed_threshold_audit.json을 함께 저장했다. PPE 72장 확대 버전은 아직 재학습하지 않았다.

같은 개발 시험 11장(사람 18개, 지게차 11개), confidence=0.25, IoU=0.5에서 기존 v2와 새 v4를 비교했다.

- 사람: 기존 TP 2 / FP 1 / FN 16 → 새 TP 12 / FP 5 / FN 6.
- 지게차: 기존 TP 5 / FP 2 / FN 6 → 새 TP 9 / FP 5 / FN 2.

누락은 줄었지만 오탐도 증가했다. 최종 발표 모델로 확정하지 않는다. 이전 3장짜리 시험 mAP와 현재 11장의 mAP를 직접 비교하지 않는다. 기존 모델 비교 결과는 `logistics_pilot_v2/expanded_test_audit.json`에 별도로 보관했다.

체류 영상에 새 객체 모델과 기존 PPE v2를 연결해 원본 프레임 간격 12로 39개 프레임을 처리했다. 사람 박스가 총 31회 출력됐으며 이는 인원 수나 정확도가 아니다. 확인한 시작 프레임에서 설비 앞 앉은 작업자를 놓쳤고, 약 7.5초 프레임에서는 통로와 오른쪽 작업자를 잡지만 설비 앞 작업자는 놓친다. PPE 검출은 0이다. ROI·추적·체류 알림은 연결하지 않았고 출력 risk_status는 not_evaluated다. 결과는 `outputs/video_validation/dwell_v4`.
