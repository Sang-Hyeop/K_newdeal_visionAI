# 기존 PPE 모델 검증

- 기존 YOLO26n PPE 모델을 safety 환경에서 실행. 새 학습 없음.
- 기존 평가 데이터 test 22장: precision 0.822 / recall 0.674 / mAP50 0.799 / mAP50-95 0.339. 기존 라벨에 대한 점수이며 CCTV 성능을 대표하지 않음.
- 시연 프레임 2장(conf 0.25): imgsz 416에서는 검출 수 1/0; imgsz 640에서는 6/0. 검출 개수는 정답 수나 정확도가 아님. 클래스 오류는 미리보기에서 별도 확인.
- 표본 PPE 라벨은 안전모만이 아닌 착용 머리를 감싸며, 착용자가 있는데 박스가 빠진 사례를 확인함. 미착용 이미지에서도 후방 일부 머리는 미라벨 상태로 보임. 382장 전체 라벨 시각 검수는 아직 완료하지 않음.
- 파일 형식 검사는 통과했지만 클래스 의미와 라벨 완전성은 보완 필요.
- 추가 영상 Logistics Warehouse.mp4: 272초,1280x720,24fps,6528프레임. 기능별 영상 5개 이후 종합 시연용. 메타데이터 확인만 수행했으며 실제 장면과 이벤트는 미검토.
- 다음 작업: 기존 PPE 데이터의 박스 정의 통일·누락 보완 및 CCTV의 작은 머리/후드/가림 사례 보강. 물류 학습 라벨 분석·사람/지게차 표본 변환 병행.

640 PPE 장면 육안 확인: 착용자 4명의 머리 위치를 찾았으나 일부 머리에 Helmet/No Helmet 중복 판정이 발생함. 후드 머리는 놓침. 따라서 검출 수 6을 성능 개선 완료로 해석하지 않음.
