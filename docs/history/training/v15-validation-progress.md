# 추가 학습 중간 검증

v15는 기존 YOLO26n 기반 v6를 초기값으로 451장에 추가 학습 중이다. 2회차까지 완료했을 때 best.pt를 별도 복사하고 동일한 고정 조건(confidence 0.25, IoU 0.5, 640px)에서 비교했다.

- 새 평가 40장: 사람 TP21→30 / FP19→17 / FN19→10. 지게차 TP27→28 / FP10→4 / FN13→12.
- 기존 평가 11장: 사람 TP12→9 / FP5→6 / FN6→9. 지게차 TP10→10 / FP2→1 / FN1→1.

새 자료에서 개선이 있지만 기존 사람 검출이 퇴행했으므로 교체하지 않았다. 중간 결과를 최종 학습 성능으로 보고하지 않는다. 두 평가 묶음은 개발용 자료이며 독립 현장 성능을 보장하지 않는다.

현재 학습 완료를 기다리는 로컬 검증 프로세스도 실행했다. 학습이 test_metrics.json을 정상 저장하면 최종 best.pt를 별도 보존하고 새/기존 평가 및 전진·후진 시연 영상 처리를 순서대로 실행한다. 결과는 outputs/diagnostics/v15_final_validation에 기록한다. 자동 승격·main 병합은 하지 않는다. 완료 후 영상의 실제 누락/오탐을 시각적으로 확인해야 한다. 학습 종료 신호가 없으면 2시간 뒤 timeout 상태를 기록한다.
