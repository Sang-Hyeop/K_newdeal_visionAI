# 발표 1번 고정 설비·적재물 오탐 정정

사용자 2026-10-14 검수: 약 1초 중앙 PERSON 박스는 기계이며, 약 2.4초 왼쪽 FORKLIFT 박스는 적재 박스다.

기존 카메라별 exclude_confirmed_equipment 경로를 이용해 두 고정 영역과 제외 클래스를 configs/video2-object-review.json에 기록했다. 입력은 현재 발표 1번이며 내부 카메라 프로필은 이전 후진 영상(2번) 설정이다. 프레임 시각을 사용하지 않고 영상 전체의 현재 관측 후보에 적용한다. 잘못된 사람·머리·차량 후보는 추적·거리·PPE 연결 전에 제외하고 진단 로그에는 제외 사유를 남긴다.

고정 영역에 대부분 포함된 후보만 제외한다. 해당 카메라와 사용자가 확인한 고정 설비·적재물에 한정된 후처리이며 모델 재학습이 아니다. 설비 위치나 카메라가 바뀌거나 실제 사람이 해당 영역을 가릴 경우 재검수가 필요하다.

새 결과 전체 재생과 실물 작업자·이동 지게차 보존을 확인한 뒤 이 채팅에서 전달한 이전 발표 1번 MP4를 삭제한다. 비교·검증용 JSONL은 보존하며 원본 입력 영상은 유지한다. 평가 체크리스트 3·6·8(오탐 영향, 회귀 검증, 인계)에 기여한다.

검증 결과: 중앙 기계 오탐 7개, 왼쪽 적재물 오탐 3개를 제외했다. 그 외 객체 검출 292개는 이전 결과와 전부 일치했다. 전체 106프레임 디코딩 확인, 테스트 210개 통과. 최신 영상: outputs/reviews/1_forklift_worker_collision_risk_latest.mp4. 이전 전달본 3종과 이 채팅의 중간 생성 MP4를 삭제했고 검증 JSONL은 유지했다.
