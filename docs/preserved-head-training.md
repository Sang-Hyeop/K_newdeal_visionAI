# 사전학습 분류층 보존 실험

학습 이미지 두 장을 진단했을 때 v7은 앉은 작업자의 전체 화면 후보에 낮은 신뢰도(약 0.065/0.089)를 주었고, 확대 크롭에서도 올바른 사람 검출을 유지하지 못했다. 원래 COCO 사전학습 모델은 같은 크롭에서 약 0.36/0.60의 사람 박스를 출력했다. 이미지 확대만으로 v7 문제를 해결했다고 주장하지 않는다.

설치된 Ultralytics 8.4.153 Detect 코드와 실제 모듈을 대조했다. YOLO26n의 COCO 80클래스 분류 특징층은 폭 80이고, 일반 2클래스 구성은 폭 64다. 크기가 다른 분류 특징 가중치는 통상적인 모양 일치 가중치 전이에서 복사되지 않는다. 이것은 원인 후보이지 유일한 원인이 확정된 것은 아니다.

scripts/train_preserved_head.py는 사전학습 모델을 복제하고 두 분류 분기의 마지막 출력 Conv만 두 클래스로 줄인다. 사람은 COCO person(0), 지게차 초기값은 COCO truck(7)을 복사한다. truck 초기값은 학습된 지게차 분류기가 아니다. 나머지 분류 특징층과 위치 예측 구조는 보존한다. 기존 사람/트럭 raw logits이 0 이미지에서 변경 전후 동일함을 확인했다. 출력 이름은 person/forklift 두 개이며, 커스텀 신경망 클래스 없이 표준 Ultralytics 모듈을 저장한다.

동일 v7 데이터(train57/val8/test11), 12 epoch, AdamW 0.0003, 기본 backbone 첫 10레이어 freeze로 새로운 v8 실험을 수행한다. 이미지 추가 효과와 초기화 효과를 구분하기 위해 데이터는 변경하지 않는다. 기존 표준 학습 스크립트로 다시 학습하면 내부 폭이 재구성될 수 있으므로 이 보존 방식의 가중치로 후속 학습할 때 구조 보존을 별도 확인해야 한다. 모든 시연 결과는 개발 진단이며 최종 독립 시험이 아니다.

## 완료 결과
12 epoch 학습과 저장 가중치 재로딩 완료. 기존과 동일한 11장 개발 시험(conf 0.25, IoU 0.5, imgsz 640)에서 사람 TP11/FP6/FN7, 지게차 TP6/FP9/FN5로 v7보다 퇴행했다. 최종 또는 기본 모델로 승격하지 않는다.

체류 영상의 0/7.5/15초를 v7/v8 각각 640/1280으로 비교했다. v8 1280에서 앉은 작업자는 7.5초 약 0.325, 15초 약 0.591로 검출되지만 0초는 누락이다. 7.5초의 주황색 설비를 forklift 약 0.260으로 오탐하며 중복 사람 박스도 있다. 세 프레임 관찰로 지속 추적·체류 감지 성공을 주장하지 않는다. 해상도 증가만으로 전반적 개선이 증명되지 않았다.

실험 모델: models/pilot_v8_preserved_head/person_forklift.pt. 상세 예측: outputs/diagnostics/v8_resolution/predictions.json. 학습 초기 진단: outputs/diagnostics/seated_worker/v7_vs_pretrained.json. 72장 안전모 데이터 추가 학습은 별도 실험으로 진행한다.
