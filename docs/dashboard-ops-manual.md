# 시선 대시보드 운영·시연 매뉴얼

관제 화면은 **영상 · 위험 요약 · 이벤트 목록 · 운영 경보** 위주로 쓴다.
판정 임계값·정책 설명은 카메라 상세에 붙이지 않고, 이 문서와 설정 파일을 본다.

평가 항목 5·7·8(화면 흐름·활용 범위·문서)에 대응한다. 시연 점수만으로 현장 일반화를 주장하지 않는다.

## 화면에서 하는 일

1. 로그인 후 **메인 관제**에서 6카메라 개요·KPI·위험 오버레이를 본다.
2. 사이드에서 카메라를 열어 **해당 구역 영상**과 상단 위험 요약·이벤트 표를 확인한다.
3. 종(벨)은 위치·이유를 짧게 확인하고 **조치 관리**로 이동한다. **경보·조치 관리**에서 대응을 남긴다.
   - 흐름: 신규 → 담당자 확인 → 조치 중 → 조치 완료
   - **감지 상태**와 **대응 상태**는 별개. 관측이 끊겨도 조치 완료로 자동 바뀌지 않음
   - 카메라 영상 확인은 해당 카메라의 N만 ✓로 변경한다. 대응 상태는 관리 페이지의 명시적 버튼으로 변경한다.
   - 조치 완료 ≠ 현장 안전 보증
   - **미완료 사건 / 전체 경보**를 같은 페이지에서 조회한다. 종전 통합 알람 메뉴는 전체 경보로 통합했다.
   - **이벤트 이력**은 감지 결과 조회, **운영 통계**는 저장 사건·처리 상태 집계다.
   - 상세는 [운영 경보 관리 정책](alert-ops-policy.md)

대시보드에서 임계값·모델을 바꾸는 UI는 없다.

| 카메라 | 구역 | 보는 기능 |
|--------|------|-----------|

| CAM02 A2 | 자동화 설비구역 | 위험구역 침범 · PPE |

| CAM04 A4 | 작업자 교차통로 | 위험구역 체류 |

기능·장면 기준은 [영상별 시연 계획](demo-feature-show-plan-2026-10-07.md), 감지 범위는 [감지 목표](detection-goal.md).

## 판정 기준은 어디에 있나

화면이 아니라 **설정 파일**이 기준이다. 모델·승인 PPE 정책은 잠금 상태이며, 사용자 요청 없이 바꾸지 않는다.

| 구분 | 위치 |
|------|------|
| 최종 모델·범위 잠금 | `configs/final-model-lock.json`, [models/README.md](../models/README.md) |
| 승인 PPE 정책 | `configs/ppe-user-approved-policy-2026-10-15.json` |
| 카메라별 시연 설정 | `configs/cameras/` (예: `reverse-proximity.json`, `dwell-demo.json`) |
| 화재 temporal 등 | `configs/review/fire-current.json` (표시·검증 근거) |
| 이벤트 출력 계약 | [detection-output-contract.md](detection-output-contract.md) |

표시용으로 설정을 읽어 문구를 만드는 코드는 `dashboard/criteria_runtime.py` · `dashboard/judgment.py`에 남아 있으나, **카메라 UI에는 노출하지 않는다.**

## 해석 한계 (운영 시 말할 것)

- 거리는 **화면상 상대값(px 등)** 이며 실제 m가 아니다.
- 관측이 없거나 불확실하면 **미확인**이다. 미확인·관측 소실을 안전·종료로 말하지 않는다.
- 화재는 불꽃 의심 관측이며, 연기만으로 경보하지 않는다.
- 운영 경보의 확인함은 **운영자 확인 상태**일 뿐, 위험이 끝났다는 뜻이 아니다.

## 2026-10-19 메뉴·확인 표시 정리

- 메인·카메라 화면 구성과 영상·모델은 유지한다. 하위 메뉴는 경보·조치 관리 / 이벤트 이력 / 운영 통계다.
- 오른쪽 경보는 로그인·메인 초기화 시 시작한 독립 세션 시계를 따른다. 다른 페이지 방문이나 개별 카메라 재생 시작은 이 시계를 초기화하지 않는다. 영상 일시정지·탐색과는 별개인 기존 시연 방식이다.
- N은 새 위험 영상 확인 필요, 녹색 ✓는 해당 영상 확인함이다. 위험 해소나 조치 완료를 뜻하지 않는다. 다른 카메라 N은 유지되며 새 독립 위험/중요도 상승 때 다시 N이 켜진다. 단순 반복 갱신은 재점등하지 않는다. 확인 여부는 현재 브라우저 페이지 범위다.
- 운영 통계는 저장된 link_key별 사건을 센다. 기간은 실제 사건 등록일 기준이다. 처리 시간은 서버 등록부터 최초 확인/완료까지이며 영상 발생부터의 대응시간이 아니다. 없는 기록은 0으로 채우지 않는다. 통계는 진입 시 1회 및 명시적 새로고침으로 갱신한다.
- 사건 목록 자동 조회는 보이는 페이지에서 최대 10초 간격이며, 변경 없는 상세는 재조회하지 않는다. 편집 중 메모는 자동 조회로 덮지 않는다.
