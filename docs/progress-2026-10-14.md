# 2026-10-14 작업 정리 및 베타 테스트 인계

## 현재 결과

최종 발표 입력을 기능별 4개와 종합 1개로 정리했다. 발표 번호 1~5와 기존 실행기의 내부 번호는 다르며, 내부 번호를 바꾸지 않고 파일명·실행 대응을 기록한다. `configs/demo-videos.json`이 현재 5개 원본의 해시·크기·길이 기준이다. 이전 7개 메타데이터는 `docs/history/presentation-video-metadata-before-2026-10-14.json`에 보존한다.

1. 충돌 위험: `1_forklift_worker_collision_risk.mp4` → 내부 시나리오 2.
2. ROI 침범: `2_restricted_zone_intrusion.mp4` → 별도 ROI 실행기.
3. 안전모: `3_PPE_Helmet.mp4` → 내부 시나리오 5.
4. 위험구역 체류: `4_hazard_zone_dwell.mp4` → 내부 시나리오 4.
5. 종합: `5_Logistics Warehouse.mp4` → 내부 시나리오 7.

과거 내부 1·3·6은 기본 리뷰 실행에서 제외한다. 과거 결과를 새 발표 번호의 결과로 해석하지 않는다.

## 오늘 변경한 동작

- 공통: 미확인을 관측 대기·판정 불가·관측 소실로 구분한다. 판정 불가를 안전으로 바꾸지 않으며 기능별 이벤트 근거를 유지한다.
- 1번: 사용자 확인 기계 PERSON 및 적재물 FORKLIFT 오탐을 카메라별 후처리로 보완했다. 사용자 리뷰 통과.
- 2번: 로봇 앞 위험구역에 현재 작업자 발점이 들어오면 즉시 침범 위험으로 처리하는 별도 실행기와 공통 이벤트 로그를 연결했다. 사용자가 결과 확인 후 3번으로 진행했다. AI 생성 영상이며 실제 CCTV 일반화 평가가 아니다.
- 3번: 현재 PPE v6 및 사람 주변 확대 관측을 사용해 최종 입력으로 이벤트와 화면을 재생성했다. 사용자가 확인 후 4번으로 진행했다.
- 4번: 빈 설비 참고 이미지와 현재 프레임을 비교해 기계 오탐을 제외하고, 실제 이동 작업자는 유지하도록 보완했다. 중복 몸 박스·상태 표시를 정리했다. 고정 영역을 무조건 지우던 이전 보완의 누락 문제를 수정했다.
- 5번: 기존 박스 경계 거리와 밑면 중앙 거리의 비교·전체 영상 검증을 진행했다. 최신 보완본은 bottom_center 실험이며 화면상 상대 거리다.
- 5번 차량/탑승자: 두 모델의 현재 전체/확대 관측으로 차량을 복구하고, 탑승자 역할의 시간적 연속성을 연결했다. 확인된 탑승자는 모든 보행자–차량 거리에서 제외한다. 역할 확인 대기는 미확인으로 남긴다. 적재물 오탐을 제한하기 위해 추가 차량 후보에 현재 사람의 공간적 맥락도 요구한다.
- 생성 결과는 workspace의 `outputs/reviews/`에 보관한다. 학습 가중치·생성 영상·대용량 원시 로그는 Git 제외이며 코드·설정·원본 시연 MP4·검증 기록을 Git으로 공유한다.

## 실행 예시

`safety` 환경에서 실행한다. 출력은 아직 없는 새 디렉터리로 지정하고 필요한 가중치를 `models/`에 별도로 준비한다.

```sh
conda activate safety
python scripts/run_demo_scenarios.py --videos 2 --ppe-final --sample-fps 5 --output outputs/diagnostics/beta_presentation1
python scripts/run_intrusion_review.py --output outputs/diagnostics/beta_presentation2
python scripts/run_demo_scenarios.py --videos 5 --ppe-final --sample-fps 5 --output outputs/diagnostics/beta_presentation3
python scripts/run_demo_scenarios.py --videos 4 --ppe-final --sample-fps 5 --output outputs/diagnostics/beta_presentation4
```

5번 최신 차량 복구·탑승자 실험의 재현 명령은 `docs/video5-vehicle-rider-recovery-2026-10-14.md`를 따른다. 일반 `--videos 7` 실행만으로 복구용 추가 추론이 자동 실행되지는 않는다. `--temporal-riders`와 `--proximity-geometry bottom_center`는 명시적으로 선택하는 실험 옵션이다.

## 검증 근거와 남은 한계

- 감지 모듈 자동 검사 248개 통과(차량/탑승자 보완 시점). 5번 전체 870샘플과 181.25초 출력의 프레임 일치·탑승자 쌍 제외·역할 대기 경고 금지·PPE 원시 관측 보존을 검사했다.
- 16.04초 왼쪽 차량, 27.71초·58.33초 지붕 없는 차량 복구를 확인했다. 27.71초 별도 하단 보행자는 유지했다. 175초 적재물 추가 오탐은 후속 후보 검수로 제거했다.
- 7.5초처럼 탑승자 최초 관측이거나 가림이 심한 구간은 미확인이 남는다. 관측 개수 증가·경고 감소는 정확도 개선율이 아니다.
- 거리 보정이 없어 미터 거리나 실제 충돌 확률을 제공하지 않는다. 추가 확대 추론의 실시간 처리 속도는 별도 측정 대상이다.
- 카메라별 설비 참고 이미지·ROI·제외 영역은 다른 장소에 그대로 적용할 수 없다. 시연 적응 결과를 독립 현장 성능으로 발표하지 않는다.
- 평가 체크리스트 2·3·4·5·6·8: 모델/규칙 선택, 처리 연결, 화면, 오류 재현과 인계 기록에 기여한다.

상세 검증은 `docs/presentation-review-2026-10-14.md`, `docs/proximity-geometry-comparison-2026-10-14.md`, `docs/video5-vehicle-rider-recovery-2026-10-14.md`, `docs/checkpoints/2026-10-14/vehicle-rider-recovery/`를 확인한다.
