# 지게차 혼동 사례 보완 데이터

기존 AIHub TS_07 train 후보 중 102,103,104,106,107,108의 전체 화면을 검수해 추가했다. 사람 6개와 지게차 6개 라벨을 포함한다. 104와 106의 차량 범위는 육안으로 보완했고, 나머지는 기존 라벨을 확인했다. 축 정렬 박스는 차량과 겹치는 화물 픽셀을 완전히 배제할 수 없으며 정밀 분할 정답이 아니다.

102/103/107의 상자·선반 부분에서 객체 없는 크롭 3장을 만들었다. 사람이 없다는 전체 화면 육안 검수와 기존 객체 박스 교차 검사를 수행했다. 라벨 파일이 빈 것은 정상 배경 예제이며 box/pallet 클래스를 추가한 것이 아니다. 같은 원본에서 파생된 크롭은 독립 장면 수로 세지 않는다.

새 데이터는 logistics_v9_hard_examples, 총85장(train66/val8/test11)이다. v7의76장에9장을 추가한 구성으로, v5의165장과 합산하지 않는다. 검증·시험 이미지 및 라벨은 바이트 단위로 그대로 유지했고 추가 자료의 site/group이 held split과 겹치지 않는다. 시연 영상 프레임을 추가하지 않았다. 기존 개발 시험을 반복 사용하므로 최종 독립 현장 평가가 아니다.

재현: safety 환경의 저장소 루트에서 `python scripts/prepare_hard_examples.py`. 기존 출력은 덮어쓰지 않도록 보호한다. 로컬 후보 색인과 원본 ZIP이 필요하다. 원본 ZIP은 자동 다운로드하지 않는다.

현재는 prepared_not_trained이며 성능 향상을 주장하지 않는다. 다음 실험은 v6 기준 가중치에서 낮은 학습률로 추가 학습하고, 같은 시험의 사람/지게차 TP·FP·FN과 시연 누락·오탐을 비교한다. 재학습 결과가 개선되지 않으면 기본 모델을 교체하지 않는다.

코드·검수 레시피·검수 기록을 로컬 Git에 저장하고, 신규9장/라벨·manifest·설정21파일은 별도 SHA 확인 복구 사본으로 보관한다. 같은 디스크의 사본이며 외부 백업은 아니다. GitHub push/main 병합은 이번 단계에서 수행하지 않았다.
