# 감지 모듈 담당자의 최종 목표

사용자(김상협)가 2026-10-06 확정한 팀 프로젝트 역할의 기준이다.

## 목표
우리가 직접 추가 학습한 YOLO 모델로 새로운 산업현장 영상에서도 작업자·지게차·안전모 및 안전모 미착용 상태를 검출하고, 재사용 가능한 감지 모듈을 완성한다.

## 역할과 결과물
- 학습 모델: 작업자·지게차·안전모·미착용 머리를 검출한다. 클래스와 후드·가림의 라벨 기준은 데이터 준비 전에 확정한다.
- 추적·후처리: 지게차–작업자 충돌 위험, ROI 침범, 체류 시간, 작업자별 안전모 상태를 판단한다.
- 카메라별 설정: ROI와 거리 기준/보정 정보를 지정한다.
- 팀 전달물: 학습한 가중치, 실행 코드, 설정 예시, 이벤트 출력 형식, 실행 방법, 검증 결과.

## 진행 기준
- 현재 기능별 영상 6개(위험구역 체류 포함)와 종합 영상 1개는 시연·검증 후보이며, 특정 영상의 시간표에 맞춘 알림을 구현하지 않는다.
- 실시간 CCTV 연결은 초기 시연의 필수 조건이 아니다. 저장된 영상을 같은 파이프라인으로 처리한다.
- 모델만으로 위험구역·실제 거리·체류 규칙이 자동 결정된다고 가정하지 않는다.
- 새로운 영상에 대한 성능은 학습에 쓰지 않은 영상으로 확인한다. 인접 프레임이 학습·검증에 섞이지 않도록 영상/현장 단위로 분리한다.
- AI 생성 영상에서의 성공을 실제 CCTV 일반화 성능으로 단정하지 않는다.
- 가림이나 낮은 신뢰도로 판단할 수 없으면 미확인 상태로 처리하며 안전/미착용으로 단정하지 않는다.
- 개발과 실행에는 safety 가상환경을 사용한다.

모델 학습, 데이터 선정, ROI, 후처리와 팀 인계의 결정은 이 목표를 기준으로 한다. 사용자가 목표를 변경하면 이 문서도 갱신한다.

## 기능별 판정 분리 (2026-10-07 확정)
- 구역 접근·침범·체류는 해당 영상의 고정 다각형 ROI로 판단한다.
- 사람–지게차 근접은 고정 위험구역 ROI로 검출을 걸러내지 않고 화면 전체의 관측된 두 객체로 판단한다. 현재는 사람 높이로 정규화한 화면상 거리이며 미터나 실제 충돌 예측으로 단정하지 않는다.
- 미터 표시는 실제 길이가 알려진 바닥 기준점과 카메라 보정을 확보·검증한 영상에서만 도입한다. 현재 자료에는 검증된 보정이 없어 distance_meters=null로 유지한다.
- 기능별 적합한 영상으로 검증·시연하며, 기능의 SAFE와 전체 현장의 안전을 동일시하지 않는다.

## 2026-10-07 확정: 지게차 통로 조건부 감시
- 왼쪽 기계 작업영역과 초록색 보행로는 허용구역이다. 중앙 노란선 사이만 통로 ROI로 수정했다. 사람의 바닥 기준점이 통로 내부이고 지게차가 검출되지 않으면 체류시간과 관계없이 WARNING이다. 지게차가 같은 통로에 관측되면 CRITICAL이다.
- 지게차 미검출은 부재 증명이 아니다. 관측된 차량이 사라지면 1초 동안 최근 위험을 유지하며 vehicle_observation_status=unconfirmed와 마지막 관측 경과시간을 기록한다. 이후 UNKNOWN으로 전환하고 같은 차량의 관측된 이탈 또는 장면 초기화로 해제한다. ID 변경/가림은 미확인을 지속시킬 수 있다.
- dwell_time_band는 기존 3초/8초 체류 구간을 보존하는 근거이며 최종 severity와 다르다. 8초 이상이어도 차량이 검출되지 않으면 WARNING이다. 통로 밖 SAFE는 해당 구역 판정만 뜻하며 전체 안전이 아니다. 운전자 포함 가능성·잘린 차량은 미확인 처리한다. 근접은 계속 full_frame, 거리 단위는 image_plane이다.
- 4번 영상 92샘플 검증: 통로 작업자 최대 관측 체류 14.598초, WARNING 유지, 16.266초 이탈. 왼쪽 작업자와 초록색 보행로는 통로 밖. 실제 영상의 차량 존재 CRITICAL은 아직 검증하지 못했고 자동 테스트로 확인했다. 설비→사람 오탐과 안전모 미착용/후진 지게차 미탐은 남는다.
- 자동 테스트 54개 통과. 신규 학습 없이 v16 유지. 이전 넓은 기계영역 ROI 결과는 역사적 결과이며 현재 시연 기준이 아니다. 다음은 기능 확대보다 실제 미탐과 차량 존재 구간 검증을 우선한다.

## 2026-10-07 사용자 승인: 시연 환경 보완 학습
사용자가 시연 영상을 학습에 넣어 미탐을 우선 보완하도록 명시적으로 승인했다. configs/review/demo-adaptation-v1.json의 검수 장면에 한해 기존 시연 제외 원칙을 변경한다. 학습에 노출된 영상의 개선은 시연 환경 적응 결과이며 독립 일반화 성능으로 발표하지 않는다. 기존 v16·평가 분리는 보존하고, 검출되지 않은 객체는 계속 미확인으로 처리한다.

같은 사용자 승인 범위에서 configs/review/demo-ppe-adaptation-v1.json의5/6번 영상 검수 장면을 별도 PPE 보완 학습에 사용한다. 후드로 가린 머리를 미착용 정답으로 강제하지 않는다.
