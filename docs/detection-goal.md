# 감지 모듈 담당 목표

김상협 담당: 작업자·지게차·안전모/미착용 머리 검출, 추적·후처리, 카메라별 ROI와 위험 판정, 팀 전달용 이벤트 출력. 기존 CCTV 영상과 PC를 활용하며 저장 영상도 같은 처리 흐름으로 분석합니다.

## 현재 범위

발표 원본은 1~5번입니다. [영상별 시연 기준](demo-feature-show-plan-2026-10-07.md), `configs/team-runtime-index.json`, `handoff.py`를 기준으로 실행합니다. 사람–차량 근접과 고정 ROI 침범·체류를 분리하며 PPE는 2·3·5번에서 사람 탐지와 함께 사용하며, 1번은 근접만, 4번은 체류시간만 표시·기록합니다.

- 관측이 없거나 불확실하면 미확인입니다. 기능별 SAFE를 현장 전체 안전으로 표현하지 않습니다.
- 현재 거리는 보정되지 않은 화면상 상대 거리입니다. 실제 m는 제공하지 않고 distance_meters=null을 유지합니다.
- 시각을 지정해 경고를 삽입하지 않습니다. 실제 객체 관측과 영상 timestamp로 판단합니다.
- 확정 탑승자는 보행자 위험 판정에서 제외하고 가림·하차·역할 대기의 한계를 기록합니다.
- 사용자 승인으로 일부 시연 장면을 보완 학습에 사용했습니다. 해당 결과는 시연 적응이며 독립 현장 일반화 성능이 아닙니다. 별도 평가에서는 원본 영상/현장 단위로 분리해 인접 프레임 누출을 방지합니다.
- 직접 라벨링한 데이터와 수정 이력을 보존합니다. 라벨 수정이 이미 학습된 모델을 바꾸지는 않으므로 재학습·비교 후 채택합니다.
- 개발과 실행은 safety 환경을 사용합니다. 기본 실행의 캐시 재사용과 --fresh 원본 신규 추론을 구분해 설명합니다.

최종 전달물은 모델·코드·설정·출력 계약·실행 방법·검증 결과와 한계입니다. 기능·성능 판단 전 [평가 체크리스트](evaluation-checklist.md)를 확인합니다.
