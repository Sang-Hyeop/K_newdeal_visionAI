# 데이터 확대 및 품질 개선 체크포인트

전체 읽기 가능한 파일 시스템의 메타데이터를 검색했다. 약 181만 파일 경로를 확인했지만 운영체제 접근 오류 861건이 있으며, 모든 파일 내용이나 모든 압축파일을 검수했다는 뜻은 아니다. 개인 파일 경로가 포함된 전체 목록은 Git에 올리지 않는다.

기존 물류창고 TL/TS07 94,238쌍과 TL/TS04 38,296쌍에서 765장을 추렸다. JPEG 엄격 디코딩 검사는 모두 통과했다. 표본 72장과 일부 개별 확대 영상을 확인했고, 운전자가 보이는데 사람 라벨이 없는 5개 영상 그룹을 확인했다. 이 원본 라벨 누락이 기존 문제에 기여할 가능성은 있으나 학습 퇴행의 단독 원인으로 입증한 것은 아니다.

해당 그룹과 운전자 라벨 누락 가능성이 높은 장면 192장을 보수적으로 제외했다. 새 묶음은 train 451 / val 82 / test 40장이다. 분할 간 영상 그룹 중복과 정확히 같은 픽셀 이미지 중복은 없다. 573장 전체를 수동 라벨 검수한 것은 아니다. 운전자가 없는 지게차 장면도 제외될 수 있어 선택 편향이 존재한다. test도 개발용 평가이며 독립 현장 성능 검증이 아니다. 시연 영상은 학습에 넣지 않았다.

YOLO26n 기반 기존 v6 가중치를 초기값으로 추가 학습 v15를 시작했다. 20 epochs / 640px / batch 4 / AdamW lr 0.0003 / warmup bias lr 0.0003 / CPU. 구조를 새로 만들지 않았다. 저장 시점에서 학습 중이며 성능 향상 여부와 최종 모델 승격은 미확정이다.

다음 검증: 동일한 새 평가 묶음에서 v6와 v15 비교, 기존 평가 및 시연 영상의 누락·오탐 비교. PPE 데이터 확대와 실제 거리 보정은 이번 사람·지게차 데이터 확대와 별개로 남아 있다.
