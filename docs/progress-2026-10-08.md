## PPE 색상·미착용 보강 학습 (2026-10-08)

- `datasets/aihub_smartyard`에서 안전모 착용/미착용 각각 30장 규모의 head-level context crop을 추가 검토했다. 자동 색상 추정은 실제 안전모 색과 다를 수 있어 학습 선정에 사용하지 않았다.
- 로컬 Hard Hat Detection 데이터의 색상 다양 장면을 원본 크기로 검수하고 노랑·빨강·파랑·흰색 안전모가 보이는 장면을 선별했다. 단, 기존 PPE 클래스 정의는 `helmeted_head` / `no_helmet_head`이므로 머리 위치와 박스 라벨이 불확실한 후보는 제외했다.
- 1차 후보 생성 중 이전 PPE val/test와 같은 Roboflow visual group 및 AIHub holdout 날짜가 새 train 후보에 섞이는 것을 발견해 학습을 10 epoch 지점에서 중단했다. 해당 run/dataset은 사용하지 않는다. 수정 후 생성한 `ppe_color_expansion_v2`는 새 Roboflow holdout visual group과 AIHub holdout 날짜 중복이 0건이며, 기존 검증 12장·테스트 9장 파일을 바이트 단위로 보존했다.
- 새 데이터 구성: 기존 255 train samples에 Roboflow 20장, AIHub 착용 27 crop, 미착용 22 crop을 더해 324 train samples. 검증/테스트는 각각 12/9장 유지. AIHub crop은 제한된 시퀀스 그룹에서 나왔으므로 독립 현장 일반화 데이터로 간주하지 않는다.
- 학습은 기존 `ppe_failure_context_v3/weights/best.pt`에서 시작했고, `safety` 환경에서 `ppe_color_expansion_v2` run으로 진행 중이다. `ppe_failure_context_v3`는 주력 유지; 새 모델은 고정 테스트와 1~7번 영상 검토를 통과하기 전까지 실험 후보로만 둔다.
- 데이터셋 생성 스크립트: `scripts/build_ppe_color_expansion_v2.py`; 검수 후보 인덱스/시트 생성 스크립트는 `scripts/prepare_ppe_color_expansion.py`, `scripts/prepare_ppe_roboflow_candidate_review.py`.
