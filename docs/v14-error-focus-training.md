## 영상 결과

v6/v14 각각 전진·후진0/5/10/15/20초 대표 프레임을 비교했다(총20회모델추론). v14 전체 영상은 각각106프레임, 약5fps, 기존ROI/후처리로 처리했다. 영상 판단 신뢰도0.1은 기존 파이프라인 설정이며 시험conf0.25와 다르다.

- 전진10초 실제 작업자·지게차 누락, 녹색 등화장치 person0.45 오탐을 직접 확인했다. 전체 쌍 관측 CRITICAL1/WARNING1/UNKNOWN21, 105/106프레임에서 확인 가능한 쌍 없음. 두 유효상태는 모두2.294초의 서로 다른 쌍이다. 이 프레임에서 P0:2는 지게차 부분을 사람으로 잡은 박스라 CRITICAL은 오경보다. 실제 작업자 P0:6 쌍은 WARNING 후보다. 한 프레임의 경고로 연속 대응 성공을 주장하지 않는다. 장면 변화12.095/16.058초 이후ROI는 비활성화된다.
- 후진10초 실제 지게차0.31 감지, person누락, conf0.25 대표 프레임에서 기존 설비 오탐은 보이지 않았다. 전체 쌍 관측 SAFE3/WARNING3/UNKNOWN18, 100/106프레임 확인 가능한 쌍 없음. 8.2~8.6초P0:27/F0:4 WARNING은 실제 보행자·지게차 쌍임을8.2초 프레임에서 확인했다. CRITICAL은0회다.

쌍 관측 수는 프레임 수와 다를 수 있다. 정답 객체가 아닌 박스에서도 거리 계산이 가능하므로 확인 가능한 쌍이라는 내부 상태가 정확한 감지의 보증은 아니다. SAFE는 실제 현장 안전을 보증하지 않는다. 영상 전수 정답 라벨링은 하지 않았고, 실제 미터 거리·전후면 방향·충돌 확정 기능은 없다.

## 저장 및 다음 판단

모델 재로딩과 클래스0person/1forklift 검사를 통과했다. 모델·영상·로그·지표를 보존하고 SHA256으로 같은 디스크의 복구 사본을 검증한다. 코드/검증 기록은 GitHub 현재 작업 브랜치로 업로드하며, 모델·생성 영상은 기존 Git 제외 정책에 따라 로컬 보관한다. main 병합은 별도다. 이전 모델을 교체하지 않는다.

이번23장 보완만으로는 개선이 확인되지 않았다. 소량을 추가해 짧게 학습하는 반복을 계속하기 전에, 누락·오탐을 영상별로 정리하고 사람/운전자/적재 지게차의 라벨 기준과 학습 분포·규모를 함께 점검해야 한다. 현재134장이 전체 다운로드 데이터 학습량을 뜻하지 않는다. 최종 시연 영상은 계속 학습에서 제외한다.
