# 이벤트 연동 준비 자료

실제 영상 감지 결과로 만든 네 가지 기능의 JSONL 샘플과 로컬 입력 검증 도구입니다. 모델 가중치나 영상 파일 없이 사용할 수 있습니다. 팀 운영 서버/API 구현이나 대시보드 연결 완료를 뜻하지 않습니다.

## 들어 있는 자료

- samples: 영상별 위험 접근, 통로 접근, 체류시간, 안전모 이벤트와 관측 기록.
- examples.json: 네 가지 기능의 실제 이벤트 예시.
- check_event_import.py: JSONL 형식·이벤트 해시·미확인 처리 검사와 SQLite 저장 예제.
- validated_samples.sqlite: 샘플을 넣어 확인한 로컬 DB.
- verification.json: 반복 입력 및 잘못된 SAFE 처리 검증 결과.

## 실행

압축을 푼 폴더에서 Python으로 실행합니다. Python 기본 라이브러리만 사용합니다.

```sh
python check_event_import.py --database review.sqlite samples/video4/zone_dwell/events_v1.jsonl samples/video4/zone_dwell/observations_v1.jsonl
```

이벤트는 event_id로 중복을 방지하며 원문 evidence를 보존합니다. 형식 오류가 있으면 파일·줄 번호를 표시하고 해당 입력 작업을 되돌립니다. severity=null은 미확인이므로 DB에서도 NULL로 유지합니다.

## 팀 연결 시 기준

1. events는 상태 전환 기록이며 observations는 각 표본 시점의 관측입니다. 최신 화면 상태는 observations를 기준으로 읽습니다. 이벤트가 없다는 이유로 정상으로 바꾸지 않습니다.
2. 위험 접근·침범·체류·안전모 상태를 독립적으로 표시합니다. 하나의 정상 상태가 다른 기능의 위험을 덮어쓰면 안 됩니다.
3. position_observation_status와 lane_membership은 확인된 통로 위치 근거입니다. 위험 observation_status가 unconfirmed라도 위치가 confirmed일 수 있습니다. 실제 차량 관측이 불확실하면 위험 등급을 강제로 확정하지 않습니다.
4. observed_dwell_seconds는 관측한 체류시간입니다. 사람 관측이 끊긴 시간을 임의로 누적하지 않습니다. dwell_observation_status가 unconfirmed면 저장된 시간은 마지막 근거이지 현재 관측이 아닙니다.
5. 시간은 원본 영상의 경과 초입니다. 서버 수신시각이나 실제 촬영 일시로 바꾸지 않습니다.
6. 현재 거리 정보는 화면상 거리이며 distance_meters=null입니다. 미터를 만들어 표시하지 않습니다.
7. 이 예제는 짧은 영상 표본의 인계 검증용입니다. 운영용 인증·동시 입력·API·보존기간·실시간 상태 만료는 팀 백엔드에서 구현해야 합니다.

7번 통로 샘플에는 최신 위치/위험 근거 분리 결과를 사용했습니다. 나머지는 직전 통합 실행의 실제 기록입니다. 원본 입력 샘플은 수정하지 않았으며 자동 정답 라벨로 사용하지 않습니다.
