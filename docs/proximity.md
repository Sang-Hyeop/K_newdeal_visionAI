# 사람–지게차 영상상 근접 판정 v1

상태: experimental_not_promoted. 실제 거리/충돌 예측 검증 전의 후처리 프로토타입이다.

사람·지게차를 별도 ByteTrack 인스턴스로 추적하고 독립 ID를 부여한다. 관측된 사람 발점에서 지게차 검출 박스의 하단 15% 영역까지의 최단 영상상 간격을 사람 박스 높이로 나눈다. 비율 ≤0.3 CRITICAL, ≤1.0 WARNING, 나머지는 해당 쌍의 SAFE이며 전역 안전 선언이 아니다. 상태 흔들림을 줄이는 히스테리시스 0.1을 둔다. 상수는 검증되지 않은 시연 설정이다.

박스 잘림, 운전석 내부/가림 가능성, 객체 누락은 미확인으로 남긴다. 지게차의 앞뒤는 unknown, 실제 거리(m)는 null이다. 화면 변화 감지는 보수적 휴리스틱으로 ROI를 중지하며 실제 카메라 전환 판정의 정확도도 검증하지 않았다. 입력 파일명과 SHA를 확인하여 카메라 설정 오적용을 막는다. 바닥 ROI 밖 검출은 검사 범위에서 제외되며 모두 오탐으로 단정하지 않는다.

실행(safety 환경, 저장소 루트):
```sh
python scripts/run_proximity_video.py --source data/videos/2_forklift_back.mp4 --config configs/cameras/reverse-proximity.json --weights models/pilot_v8_preserved_head/person_forklift.pt --output outputs/video_validation/proximity_v1/reverse
```

두 영상 각 106프레임 검사: 후진 SAFE 25 / WARNING 13 / CRITICAL 8 / UNKNOWN 20 쌍 관측, 확정 쌍 없는 프레임 60개. 동일 쌍의 반복 프레임을 세므로 사람 수나 정확도가 아니다. 5초와 12.4초 대표 프레임에서 실제 사람·지게차 검출을 눈으로 확인했다. 위험 후보는 12.4초에 기록되지만 실제 충돌 가능성의 정답 검증은 수행하지 않았다. 사람 ID가 P0:2에서 P0:8로 바뀌어 연속 안전→주의→위험의 동일인 추적을 입증하지 못했다.

전진 WARNING 2 / UNKNOWN 11 쌍 관측, 확정 쌍 없는 프레임 104개. 9.8초 대표 프레임의 사람·지게차는 육안 확인했지만 안정적인 전체 시연 수준은 아니다. 12.095/16.058초 화면 변화 감지 이후 ROI 중지. 지게차 누락, 상자/설비 오탐 및 추적 단절이 남아 있다.

28개 단위 검사가 통과했으며 이는 규칙 구현 검사이고 검출 정확도 검증이 아니다. 다음 작업은 보유 학습 영상의 지게차·사람·상자/설비 혼동 사례를 선별해 라벨 보완하고, 시연 영상은 학습에 넣지 않은 채 모델과 추적을 재검증하는 것이다. v8을 최종 모델로 승격하지 않았다.
