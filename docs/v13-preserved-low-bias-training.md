# v13 분류층 보존 학습·영상 검증 기록

111장(train92/val8/test11), 12epoch, safety 환경에서 학습 완료. 사전학습 YOLO26n의 분류 특징층과 person/truck 출력 가중치를 유지해 두 클래스로 초기화하고 AdamW lr0=0.0001, warmup_bias_lr=0.0001, freeze=10을 적용했다. truck 초기값은 학습된 지게차 클래스가 아니다.

## 같은 시험 11장 비교

conf=0.25 / IoU=0.5 / imgsz640. 정답 사람18개, 지게차11개.

- v6 기준: 사람 TP12/FP5/FN6, 지게차 TP10/FP2/FN1.
- v12: 사람 TP11/FP6/FN7, 지게차 TP10/FP2/FN1.
- v13: 사람 TP11/FP3/FN7, 지게차 TP7/FP8/FN4.

사람 오탐은 줄었으나 지게차 성능이 악화되어 experimental_not_promoted로 보관했다. v12와 이미지·라벨 SHA 목록은 동일하다. 초기 모델·분류 구조·동결 설정이 함께 달라 단일 원인의 효과로 단정할 수 없다. 이 시험은 개발에 반복 사용한 소표본으로 독립 최종 평가가 아니다.

## 영상 검사

v6/v13 전진·후진 각 0/5/10/15/20초 대표 프레임 비교(총20회 추론), v13 전체 영상은 각각 106프레임을 약5fps로 처리했다. 640 입력, 기존 카메라 설정 그대로 적용.

- 전진10초 작업자 감지 회복(0.775), 지게차에 중복 박스 남음. 9.38~10.01초 동일쌍 P0:22/F0:4 WARNING 4회. 전체 SAFE4/WARNING4/UNKNOWN11 쌍 관측, 98/106프레임 확인 가능한 쌍 없음. 12.095/16.058초 장면 변화 이후 ROI 재설정 필요.
- 후진10초 실제 지게차0.773 및 설비0.352 지게차 오탐, 사람 누락 확인. 12.6초는 실제 보행자/적재 지게차 쌍 P0:9/F0:1의 CRITICAL 후보를 육안 확인했다. 로그상 12.4~13.8초 CRITICAL 8회. 15초 작업자와 설비 오탐 쌍 SAFE도 육안 확인했다. 전체 SAFE100/WARNING4/CRITICAL8/UNKNOWN87 쌍 관측, 41/106프레임 확인 가능한 쌍 없음.

관측 수는 여러 쌍을 포함하므로 프레임 수와 같지 않으며, 정확도·실제 안전을 의미하지 않는다. 모든 영상 프레임을 수동 라벨링한 검증은 아니다. SAFE→WARNING→CRITICAL이 한 사람의 동일 추적으로 모두 안정적으로 이어진다고 입증하지 못했다. 사람 높이로 나눈 영상 평면 간격이며 미터·충돌 확정·전후면 방향 판단은 없다.

## 구현·저장

train_preserved_head.py에 학습률/bias warmup CLI와 실제 설정 기록 추가. 초기 가중치 보존 검사 통과. 별도 원시 출력의 완전일치 검사는 float32 오차로 실패했으며, atol/rtol=1e-5 비교는 6분기 모두 통과(최대 절대오차1.53e-5). 이는 학습 전 초기화 검사다. 학습 모델 재로딩 및 클래스 매핑 검사, 코드 컴파일 완료.

실험 모델과 검증 영상은 로컬 및 같은 디스크의 SHA256 검증 복구 사본으로 보관한다. 코드·검증 기록을 GitHub 작업 브랜치에 업로드하며, 모델/생성 영상은 현재 Git 제외 정책에 따라 로컬 보관한다. main 병합은 별도다.

다음 작업은 기존 확보 자료에서 설비·적재물 오탐 음성 장면과 가려진/작은 사람 장면을 더 검수해 보완하는 것이다. 현재 92장 train은 전체 다운로드 자료를 모두 학습한 양이 아니다. 최종 시연 영상은 학습에 넣지 않는다.
