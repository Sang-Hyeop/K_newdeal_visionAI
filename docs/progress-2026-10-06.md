# 감지 모듈 중간 저장 — 2026-10-06

## 현재 상태
작업자·지게차 감지 데이터 보완, 실제 재학습, 시연 영상 검출 시험까지 진행했다. 최종 발표 모델로 승인한 모델은 아직 없다. v4는 비교 기준으로 유지하고 v5~v7 실험 결과도 보존한다. 안전모 72장 확대 데이터는 준비했지만 아직 그 72장으로 재학습하지 않았다. 영상 시험은 기존 PPE v2를 사용한다.

## 완료한 작업
- 접근 가능한 사용자 폴더/연결된 볼륨 목록 재검색: 파일 493,464개, 압축 경로 744개, 영상 경로 959개. 관련 ZIP 31개의 내부 목록 확인. 접근 오류 499줄이며 컴퓨터 전체 내용 검수가 끝난 상태는 아니다. train 현장 영상 566개를 찾았으나 모두 라벨링·학습하지는 않았다.
- PPE: 기존 자료에서 안전모/미착용 머리 라벨을 검수해 72장(train 51, val 12, test 9) 준비.
- 객체 v4: 작은 작업자 후보 16장 중 10장 승인. 총 58장(train 39, val 8, test 11)으로 30 epoch 학습.
- 객체 v5: 압축 속 train 이미지 100장 및 train 영상 7개의 수동 라벨 크롭 7장 추가. 총 165장(train 146, val 8, test 11), 10 epoch 추가 학습. 원본 이미지 100장은 구조 검사와 7장 표본 검수이며 전부 수동 검수한 자료가 아니다.
- 객체 v6: v4에 화물·마스트 경계를 수정한 지게차 train 이미지 8장 추가. 총 66장(train 47, val 8, test 11), 낮은 학습률로 8 epoch 추가 학습. v5의 추가 107장은 이번 버전에 포함하지 않는다.
- 객체 v7: v6에 train 영상 4개에서 장면 10장 추가. 원본 전체 화면 6장과 불분명한 배경을 가린 보완본 4장, 사람 29개·지게차 4개 박스. 총 76장(train 57, val 8, test 11), 12 epoch 추가 학습. 두 후보는 보류.
- 시연 7개를 SHA-256/해상도/FPS와 함께 등록하고 학습에서 제외. v7로 1fps 샘플링 378프레임 처리, 영상·JSONL 출력 확인. 체류 영상의 겹치는 구역 4분할 추론도 시험했으나 앉은 작업자 누락은 해결하지 못했다.
- 체류 상태 계산 모듈 구현: 3초 이하 SAFE, 3초 초과 8초 미만 WARNING, 8초 이상 CRITICAL. 감지 누락은 미확인으로 처리하고 누락 시간은 더하지 않는다. 경계·누락·ID·초기화 테스트 통과. 실제 YOLO·추적·ROI 파이프라인에는 아직 연결하지 않았다.

## 동일 개발 시험 비교
같은 11장(사람 18개, 지게차 11개), conf=0.25 / IoU=0.5. TP는 맞춘 박스, FP는 잘못 잡은 박스, FN은 놓친 정답 박스다.

- v4: 사람 TP12 / FP5 / FN6; 지게차 TP9 / FP5 / FN2.
- v5: 사람 TP9 / FP5 / FN9; 지게차 TP7 / FP2 / FN4. 누락 증가로 승격하지 않음.
- v6: 사람 TP12 / FP5 / FN6; 지게차 TP10 / FP2 / FN1. 작은 시험은 개선됐지만 시연 누락이 남아 최종 모델 승인 보류.
- v7: 사람 TP12 / FP4 / FN6; 지게차 TP8 / FP5 / FN3. 일부 배경 작업자를 새로 잡지만 지게차 시험은 퇴행. 기본 모델로 교체하지 않음.

데이터 버전은 서로 겹치는 대안 구성이다. 위 장수를 합쳐 전체 고유 이미지 수로 해석하지 않는다. 작은 개발 시험을 반복 사용했으며 최종 독립 평가가 아니다. 일부 train 영상은 시연과 동일 공장/카메라 환경이다. 시연 검출 수는 인원 수나 정확도가 아니며 전체 정답 라벨은 아직 없다.

## 남은 핵심 작업
앉은 작업자와 실제 시연 각도의 지게차 누락 해결, PPE 확대 데이터 재학습과 작업자별 안전모 매칭, 추적·카메라 ROI·거리 기준 설정 및 실제 체류 영상 연결, 이벤트 인터페이스와 팀 인계 검증. 현재 영상 로그는 risk_status=not_evaluated이며 검출 결과가 곧 안전·주의·위험 판단은 아니다.
