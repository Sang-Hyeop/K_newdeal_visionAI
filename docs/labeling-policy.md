# 시선 객체 검출 라벨링 기준 — 초안 v1

## 목적과 현재 상태
새로운 산업현장 영상에 적용할 감지 모델을 만들기 위한 정답 기준이다.
현재 5개 영상에서 원본 해상도 프레임 30장을 추출했다. 아직 정답 박스는 작성하지 않았고 학습/검증 분할도 하지 않았다.
검토 이미지 경로: data/label_review/<영상명>/*.jpg
추출 정보: data/label_review/manifest.json
재실행: safety 환경에서 python scripts/extract_review_frames.py

## 클래스 ID (순서 고정)
0: person — 작업자·보행자·운전자 등 보이는 모든 사람.
1: forklift — 확인 가능한 지게차 본체·마스트·포크. 별도 적재 화물은 제외.
2: helmet — 사람이 착용하고 있는 산업용 안전모. 바닥·손·선반에 놓인 안전모는 이 정의의 대상이 아니다.
3: no_helmet_head — 안전모를 착용하지 않은 것으로 확인되는 머리. 맨머리·일반 모자·후드 포함.

## 박스 작성 규칙
- 이 초안은 보이는 부분을 감싸는 직사각형을 사용한다. 화면 밖이나 가림 뒤의 몸체를 상상해 확대하지 않는다.
- 사람과 그 사람의 안전모/미착용 머리는 각각 별도 박스를 작성한다. person 박스만으로 PPE 정답을 대신하지 않는다.
- helmet은 안전모 외곽을, no_helmet_head는 보이는 머리 영역을 감싼다. 미착용 머리에 상체 전체를 포함하지 않는다.
- 동일한 머리에 helmet과 no_helmet_head를 동시에 붙이지 않는다.
- 부분 가림이 있어도 객체의 종류가 명확하면 보이는 범위를 표시한다. 작은 머리·심한 흐림·가림으로 PPE 여부를 알 수 없으면 머리 클래스는 표시하지 않고 검토 기록에 남긴다.
- 명확한 대상을 빠뜨리지 않는다. 불확실한 객체가 많은 프레임은 학습에서 보류한다. 일반 YOLO 라벨 파일에는 '무시 영역'이 없으므로 무라벨 영역이 배경으로 학습될 수 있다.
- 지게차 마스트만 보이고 본체가 없는 프레임은 별도 검토 후 학습 포함 여부를 정한다. 일관된 본체 정의 없이 전체 지게차와 섞어 라벨링하지 않는다.
- 운전자도 person으로 표시한다. 충돌 판단 시 운전자 제외는 추적·후처리 문제로 다룬다.
- 위험·주의·안전, 전진·후진, 침범·체류는 이번 검출 클래스가 아니다.

## 현재 영상에서 검토할 사례
- forklift_forward: 사람과 지게차의 분리, 운전자, 접근 중 가림.
- forklift_back: 화물 제외 박스, 심하게 가려진 지게차의 라벨 가능 여부.
- forklift_crush: 지게차별 독립 박스, 접촉 시 겹침, 적재물 오탐.
- Helmet_forklift: 후드를 안전모와 구분, 마스트에 가려진 사람, 본체 없이 보이는 마스트.
- PPE_Helmet: 이동 중 작은 머리, 사람끼리 겹침, 착용/미착용이 명확한 프레임.

## 데이터 분리와 판정
현재 프레임은 라벨 기준 검토 전용이며 train/val/test에 자동 배정하지 않는다.
최종 검증 영상과 그 파생 프레임은 학습에서 제외한다. 동일 원본의 이어붙인 구간도 같은 그룹으로 관리한다.
인접 프레임 무작위 분할을 피하고 원본 영상/현장 단위로 분리한다.
AI 생성물은 합성 데이터로 표시하며 실제 CCTV 평가를 별도로 확보한다.
추론에서 helmet이 검출되지 않았다는 이유만으로 미착용으로 판단하지 않는다. 명확한 미착용 증거와 사람 연결·시간 안정화가 필요하다.
다음 단계는 대표 프레임에 실제 정답 박스를 붙이고 이 기준의 모호함을 확인하는 것이다.
