# v15 학습 완료 및 모델 선택

20회 학습을 완료했다. 15회 완료 체크포인트의 가중치·옵티마이저 상태를 보존하고 patience=0으로 16~20회를 재개했다. results.csv의 epoch 1~20이 중복 없이 존재함을 확인했다. 초기 가중치는 기존 YOLO26n 기반 v6이며 구조를 새로 만들지 않았다.

검증 mAP50–95가 가장 좋았던 8회차 best.pt를 사람·지게차 개발 기준 모델로 선택했다. 마지막 20회차 가중치도 별도 보존했다.

고정 평가 조건: 640px / confidence 0.25 / IoU 0.5.

- 새 평가 40장: 사람 TP21→34 / FP19→13 / FN19→6. 지게차 TP27→38 / FP10→9 / FN13→2.
- 기존 평가 11장: 사람 TP12→13 / FP5→3 / FN6→5. 지게차 TP10→11 / FP2→2 / FN1→0.

두 평가 묶음 모두 기존 v6보다 개선했다. 이 자료는 개발용 평가이므로 독립 현장 정확도 보장으로 해석하지 않는다.

전진·후진 시연 영상 각 106개 표본 프레임을 자동 처리했고, 접촉판 및 주요 시점 일부를 시각 검수했다. 전체 프레임을 정답 라벨링한 검증은 아니다. 전진 주의 알림은 3.34~3.75초, 9.38~9.59초에 발생했다. 그러나 전진 10.43초에서 지게차 검출이 끊기고, 후진 12.4~13.8초에서도 지게차 누락이 남았다. 후진 영상은 위험·주의 알림이 없었다. 106개 처리 프레임 중 확인된 사람–지게차 쌍이 없는 프레임은 전진 91 / 후진 89였다. 이 값은 정답 기반 검출률이 아니며, 모든 프레임에 쌍이 존재하는 것도 아니다.

선택: models/pilot_v15_scaled_filtered/person_forklift.pt를 사람·지게차 감지의 개발 기준으로 사용한다. 충돌 경고의 최종 시연 완성이나 현장 운영 승격은 아직 아니다. PPE 모델은 이번 학습에 포함되지 않았으며 기존 상태 그대로다.

다음 보완은 새 반복 학습부터 시작하지 않고, 가까운 순간의 지게차 누락이 원본 예측·신뢰도·ROI 중 어디서 발생하는지 확인하는 것이다. ROI와 물리 거리, 앞뒤 판단은 별도의 카메라 설정/보정 문제다.

모델·마지막 가중치·학습 기록·재개 체크포인트는 outputs/checkpoints/v15_completed20에 복사하고 SHA-256 일치를 확인했다. 같은 디스크의 복구용 백업이다. PT와 원본 학습 데이터는 Git 제외이며 코드·설정·결과·해시를 Git에 저장한다.
