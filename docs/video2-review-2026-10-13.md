# 2번 검출·표시 보완 검증

사용자0~6.4초 리뷰: 실제 지게차 미탐/앉은 작업자와 걷는 작업자의 표시 누락, 객체명 대신SAFE 표시, 화면상거리 연결선 누락. 이전 runner는1번 review route에만 객체 이름/연결선을 그렸다.2번도 독립 객체-first route를 명시하고 위험상태와 객체명을 분리한다.

지게차: 문맥 보강 후보1280 단일forklift 결과를 사용한다. 기존 baseline의 왼쪽 적재물 forklift 제안을 섞지 않는다. 사람: COCO1280+기존person/forklift baseline640+기존demo-adaptation640의 현재 프레임 사람 제안을 이름으로 합친다. conf>=.25, 중복IoU0.5 제거. 실제 앉은 작업자는demo-adaptation, 걷는 작업자는COCO가 보완한다. 동일한 수용 사람 제안을PPE 추적에도 넣어 경로 불일치를 줄인다. 새로운 학습/합성 검출/시간별 강제표시 없음.

카메라별 모델 객체를 독립 구성해1번 검수 가중치가2번 또는 다른영상의 기본묶음을 오염하지 않도록 수정했다. 모델 선택은2번 개발용/시연 후보 설정이며 전체 운영모델의 일괄승격이 아니다. 관련 현장 적응과 처리비용 증가가 있고 독립일반화검증이 아니다.

PERSON/FORKLIFT+신뢰도로 객체 표시. 연결선은 동일 작업자의 더 가까운 위험/미확인이SAFE로 가려지지 않게 유지하면서 다른 작업자의SAFE도 함께 표시한다. 운전자 가능성이 있는 사람은UNKNOWN/CHECK 관계로 유지해 추측으로안전을확정하지않는다. 화면 밖 차량 범위는clipped UNKNOWN을 유지한다. PPE는독립미확인/검토후보일수있다.
