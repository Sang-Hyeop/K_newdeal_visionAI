# 실패 유형 보완 1회: v17

이 실험은 v16의 후진 12.4~13.8초 실제 차량 누락을 해결할 수 있는지 확인한다. 새 YOLO 구조를 만들지 않고 기존 YOLO26n에서 추가 학습한 v16을 초기 가중치로 사용한다. 입력 해상도 확대(960/1280)는 사전 진단에서 해결책이 되지 않았다.

## 데이터와 라벨

- 사람0, 지게차1 두 클래스를 유지한다. 배경은 별도 클래스가 아니다.
- 15개 실제 차량 장면을 육안으로 검수했다. 심한 가림으로 차량이 거의 보이지 않는 C79/C89/C122는 추가하지 않았다.
- 운전자가 보이면 보이는 범위를 사람으로 라벨링하고, 가려진 몸을 추측하지 않는다. 지게차는 차체·마스트·포크 등 확인되는 차량 범위를 기준으로 하며 적재물의 외곽 자체를 차량 외곽으로 삼지 않는다.
- 3개 원본 프레임에서 6개 물체 없는 상자·설비 영역을 따로 검수해 빈 라벨로 추가했다. 원본 전체 프레임에는 지게차와 사람이 있으므로 원본 전체를 negative라고 부르지 않는다.
- 새 양성 15개를 각3회 반복해 표본 가중치를 부여했다. 45개의 독립 원본이라고 해석하면 안 된다. 기존466개 + 양성 반복45개 + 배경6개 = 학습 파일517개.
- 검수 영역 밖을 회색으로 가리고 영역 안 픽셀의 원래 크기와 위치를 유지한다. 이 변환은 확대 크롭 중심이었던 이전 실험의 크기 불일치를 줄이기 위한 증강이며, 회색 배경과 실제 영상 배경의 차이라는 한계가 있다.
- 기존 val82/test40의 이미지·라벨 SHA256을 확인해 그대로 보존했다.
- 실제 목표 시연 영상은 학습에 넣지 않았다. 7_tr16/7_tr18의6개 장면도 보류했다. 동일 공장·카메라의 여러 잘린 영상이므로 파일 단위 분리만으로 촬영 사건 독립성이나 새 현장 성능을 입증하지 않는다.

## 고정 실행과 판정

`scripts/train_reviewed_pilot.py`로 v16에서 6epoch, freeze10, AdamW0.0003, warmup_bias_lr0.001, imgsz640, batch4, patience0을 실행한다. best는 기존 validation으로 선택한다. 목표 영상 결과를 보고 다른 epoch를 고르거나 추가 학습을 반복하지 않는다.

학습 전 기준 v16: 목표8프레임 실제 차량 검출1/8, 추적0/8, 작업자 추적7/8. 보류6프레임 차량 검출2/6. 원본 영상의 추적 기록과 수동 박스를 IoU0.5로 대조한다. 전진·후진 영상 전체를 동일 설정으로 처리해 추적 이력과 장면 전환을 보존한다.

세부 합격 조건은 `configs/review/related-forklift-v17-protocol.json`에 있으며 `scripts/evaluate_targeted_forklift.py`, `scripts/assess_targeted_forklift_gate.py`로 판정한다. 실제 차량8/8 검출·동일 ID 추적, 실제 작업자8/8 추적, 기존40/11 검사 사람·차량 미탐 증가 없음, 보류6장 차량 미탐 증가 없음이 필요하다. 경고는 실제로 일치한 작업자·차량 쌍을 별도 확인한다. 상자 오탐에서 발생한 알림은 합격 근거가 아니다.

실패 시 `experimental_not_promoted`로 저장하고 v16을 유지하며 반복 학습을 중단한다. 검출 합격도 실제 3D 충돌의 안전 인증은 아니며, 이미지 거리·ROI 규칙은 별도 검증이 필요하다. 미확인은 안전으로 출력하지 않는다.

## 완료 결과: 불합격, 미채택

6epoch 실행 완료. 기존 validation이 선택한 best는1회차(mAP50-95=0.71161), SHA256 `1920c78562b48c64852d7a142fe9e765197b57ede90c163f0853f2895b11437e`.

- 후진 목표 실제 차량 검출1/8→4/8. 실제 차량 추적0/8→0/8. 실제 작업자 추적7/8→7/8.
- 보류된6개 가림·회전 장면 차량 검출2/6→5/6.
- 기존40장: 사람 미탐4→3, 차량 미탐2→0. 기존11장: 사람 미탐5→6, 차량 미탐0→0. 기존 검사 오탐도 늘었다.
- 실제 목표 작업자·차량 쌍에 연결된 경고는0개였다. 따라서 화면에 다른 상자·설비 트랙이나 이벤트가 있다고 해결된 것으로 세지 않는다.
- 대상 차량 검출이 일부 나아졌어도 신뢰도0.12~0.23 수준은 새 추적 시작0.25에 미달했다. 12.4초는 여전히 누락이었다. 문턱값을 낮춰 합격시키지 않았다.
- 선택 모델·설정은v16으로 유지했다. 이 보완 학습은 한 번으로 종료했으며 후속 반복 학습을 시작하지 않았다.

전체 판정: `docs/checkpoints/2026-10-07/related_forklift/v17-final-gate.json`. 모델·학습 기록·판정 백업: `outputs/checkpoints/v17_completed6`. 실패가 데이터 확보 불가능함을 입증하는 것은 아니다. 이번 크기 보완과 소량 추가 학습만으로 목표 추적 문제를 해결하지 못했다는 결론이다.
