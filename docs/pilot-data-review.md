# 학습 데이터 1차 선별 및 시험셋 초안

## 완료한 작업
PPE 382장 전부 디코딩·라벨 구조 검사, 16개 검수판 육안 확인. 이 단계는 축소 미리보기 선별이며 전 이미지 원본 해상도 정밀 검수 완료를 뜻하지 않는다.
- 형식/디코딩 오류는 발견하지 못했으나 누락·왜곡·불명확 사례 및 관련 유사 그룹 232장을 보류했다.
- 후보 150장 중 유사 원본 그룹당 1장을 택해 66장 시험 초안을 만들었다: train 46 / val 10 / test 10.
- 파일명이 다른 유사 이미지(pHash 및 수평 반전 기준)로 기존 split 간 13개 쌍을 찾았다. 13개의 독립 원본이라는 뜻이 아니다.
- 확인 예: P280/P326, P244/P329는 기존 train/valid에 나뉜 같은 장면이다. 앞선 SHA256 비교에서 중복 0이었다는 결과는 바이트 완전 동일 이미지에만 해당했다.
- 보수적 유사 그룹으로 재분리했으나 원본 출처가 확정된 것은 아니다. 새 pilot test도 이미 열람된 개발용 평가이며 최종 독립 평가셋으로 주장하지 않는다.

물류 학습 JSON 94,238개 전체를 집계했다. 25개 현장, 387개 raw_video_ID 그룹이다.
- 박스 위치 proxy: 사람 중심이 지게차 박스 밖인 후보 14,250개 / 겹치는 후보 58,991개. 실제 보행자/운전자 정답이 아니며 둘의 역할을 자동 확정하지 않는다.
- 현장과 촬영 그룹이 split 간 겹치지 않게 446장 초안을 추출: train 318 / val 64 / test 64.
- 이미지 실제 크기와 메타데이터 크기가 다른 후보 2장을 보류했다. 좌표 기준을 추측해 보정하지 않았다.
- 전 사본 디코딩·YOLO 박스 경계·이미지-라벨 페어 검사 통과. 두 초안 모두 SHA256 기준 split 간 동일 이미지 0.

## 실제 학습을 막는 품질 문제
물류 미리보기 20장 중 사람이 보이지만 미라벨인 지게차 장면, 지게차가 보이지만 person_only인 장면, 부분 지게차가 보이지만 background인 장면을 확인했다. 물류 원본도 전 클래스 정답이 완전하다고 가정하면 안 된다.
일부 지게차 박스가 화물을 포함해 body-only 기준과 다르다. 누락과 박스 정의를 수정한 사본 또는 검수 통과 부분집합이 필요하다.
PPE 후보도 원본 해상도로 작은 머리와 가림을 확인해야 한다. 46장 train은 전체 성능을 목표로 하는 충분한 데이터량이 아니라 파이프라인 시험 규모다.

## 상태와 사용 방법
모든 manifest의 training_eligible=false. pilot_v1의 dataset.yaml은 경로/클래스 연결을 위한 초안이며 지금 바로 본학습에 사용하지 않는다.
원본은 수정하지 않았고 시연 영상 6개는 포함하지 않았다. 학습 시작과 최종 모델 변경은 하지 않았다.
검수 스크립트: scripts/audit_training_pool.py, scripts/build_pilot_datasets.py.
후자는 기존 pilot_v1이 비어 있지 않으면 실행을 중단한다. 검수·수정 사본을 보존하며 재생성은 새 버전 OUT 경로에서 수행한다.

## 다음 단계

3. 학습 적합 상태를 명시한 자료만 시험 학습하고, 본학습 규모 확대 및 별도 현장 평가셋을 준비한다.
