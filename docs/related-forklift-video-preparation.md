# 시연 제외 관련 지게차 영상 프레임 준비

사용자 승인: 시연 영상 자체를 제외하고 같은 유형의 지게차가 나오는 다른 영상을 학습 자료로 사용한다. 기존 범용 v15를 보존하고 현장 보완 모델은 별도 버전으로 만든다. 같은 현장/카메라 적응을 새로운 현장 일반화로 주장하지 않는다.

Safe and Unsafe Behaviours의 train 폴더에서 과적 지게차 운반48개와 안전 운반22개, 총70개 영상을 찾았다. 각 영상15/50/85% 시점에서 프레임 후보를 추출했다. 시연 영상의 SHA256이 같은 파일을 제외하고 축소 영상의 유사도를 비교했다. 초기3개 보류 후 67개에서201개 후보를 만들었다.

추가로 원본 학습 영상과 지게차 시연3개를 약2fps로 비교했다. 영상 전체 중 일부에 시연과 거의 같은 장면이 있는3_tr7,3_tr17도 보류했다. 최종 후보는65개 파일/195개 프레임이다. 후보파일수가 독립 촬영 이벤트65개라는 뜻은 아니며 동일 녹화의 겹치는 클립일 수 있다. 이 유사도 검사가 모든 중복 이벤트를 배제했다는 보장은 없다.

첫48개 축소 표본과3_tr20의 원본1장을 확인했다. 후진 시연과 같은 공장 카메라 및 적재 지게차를 포함하고, 전진·후진·회전·원거리·근거리와 설비 배경이 있다. 전진 시연의 좁은 통로 지게차 자료를 확보했다는 뜻은 아니다.

현재 확정 위치 라벨은0장이며 학습은 시작하지 않았다. 행동 분류 폴더 이름은 YOLO 사람/지게차 박스 라벨이 아니다. 영상 파일 그대로가 아니라 프레임과 검수된 위치 라벨로 추가 학습한다.

다음: 차량 본체와 적재물 범위의 라벨 정책을 먼저 확정하고, 보이는 사람/운전자를 누락하지 않게 검수한다. 모호한 사람이나 잘린 차량은 자동 정답으로 승인하지 않는다. 검출 모델의 초안이 있더라도 검수 없이 정답으로 사용하지 않는다. 같은 녹화 이벤트의 중복 클립을 확인하고 분할을 정한 뒤 기존451장과 혼합해 별도 버전으로 추가 학습한다. 기존 평가40장/11장 성능과 시연을 다시 비교한다. 단순히 소수 크롭을 추가하고 같은 학습을 반복하는 방향은 피한다.

후보와 원본은 data/training_review/related_forklift_v1에 보존했다. manifest/중복검사/선별 목록은 같은 디스크 복구용 사본을 만들고 SHA256을 확인했다.

## 진행된 v16 보완 학습
65개 영상의 중간시점65장에 모델 초안을 만들고, 선택 장면의 원본/확대와 수정 크롭을 검수했다. 확정된15개 원본 프레임은 차량 본체·운전자 중심 문맥 크롭으로 사용했다. 먼 배경의 모호한 사람은 제외하고, 좁게 잘린 좌석 작업자는 확인되는 부분만 라벨링했다. source_frame_image_sha256 및 원본 영상 해시, 크롭/수정 박스를 configs/review/related-forklift-v16.json에 남겼다. 모델 초안을 그대로 자동 정답으로 승인하지 않았다.
기존451장과 새15장을 합쳐466장으로 학습한다. 기존val82/test40의244개 이미지·라벨은 바이트 동일하다. 후보195장 전체가 학습용으로 확정된 것이 아니고, 확정15장은 측면/운전석 가시 장면 비중이 높다. 적재물 뒤에서 차량/운전자가 크게 가려지는 정면은 아직 부족하다. 이 부족한 방향을 회차 증가만으로 해결한다고 가정하지 않는다.
초기v15 그대로 유지, 앞10개 레이어freeze, 학습률.0003,10회 보완 학습. 초기 체크포인트를8개 실패 장면에서 검사했을 때 후진 실제 차량의 신뢰도가 약.049~.058로 아직 운영.1/신규트랙.25 미만이다. 초기 검사만으로 최종 결과를 확정하지 않고 완료 후 고정 평가/영상 결과와 함께 판단한다.

## 완료 결과
10회 추가 학습 완료, 최적epoch6. v15 보존 후 고정40장/11장 평가 개선과 표본 영상 검토를 근거로 v16을 개발 기준으로 선택했다. 상세 고정 비교/후처리 수정/미해결 후진 누락은 docs/progress-2026-10-07.md와 docs/checkpoints/2026-10-07/related_forklift/v16-final-comparison.json에 기록했다. 모델 자체의 비교는 같은 기존 규칙에서 수행했고, 차량과 대부분 겹치는 사람의 잘못된CRITICAL을UNKNOWN으로 처리하는 수정은 별도영상 결과로 남겼다. 아직180후보는 확정 라벨이 없으며, 전체 안전관제 기능의 최종 완료가 아니다.
