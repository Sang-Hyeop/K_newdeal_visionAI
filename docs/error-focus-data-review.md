# 오탐·작은 작업자 자료 보완 기록

기존 다운로드 자료에서 미사용 학습 영상 그룹 40개를 후보로 추렸다. 모델 예측은 검수 우선순위 참고로만 사용했으며 자동 정답으로 채택하지 않았다. 후보 40장의 모음 미리보기와 22장의 개별 전체 화면, 배경 크롭 6개를 시각 검사했다.

전체 화면 19장과 배경 크롭 4개를 승인해 기존 111장에 추가했다. 새 버전은 logistics_error_focus_v1이며 총134장(train115 / val8 / test11)이다. 새 사람20개·지게차10개 정답 박스를 추가해 학습 정답은 사람151개·지게차78개, 객체 없는 배경11장이다. PPE는 이번 단계에서 변경하지 않았다.

## 승인 내용

- 작업자/운반 장비 전체 화면9장: ID6,31,33,34,43,52,60,61,100. 작은 작업자, 적재물에 부분적으로 가려진 사람, 수동 운반 장비·선반 배경을 포함한다. ID34는 영상 가장자리에서 머리가 잘린 사람의 보이는 범위다.
- 지게차 전체 화면10장: ID127,137,143,147,150,152,153,155,162,164. 원본 사람 높이가 56~192픽셀인 사례가 포함된다. 상당수는 운전자이며 ID155에는 운전자와 차량 밖 작업자가 모두 있다. 운전자 표본을 보행자 표본으로 간주하지 않는다.
- 배경4장: ID6의 적재물/수동 운반 장비, ID43/52의 선반·상품, ID100의 설비 구조물. 원본 정답 박스와 겹치지 않는지 확인한 뒤 크롭을 직접 검사했다. 크롭은 독립된 새로운 현장이 아니다.
- ID164 지게차 박스를 보이는 포크 끝까지 확장했다. ID153은 상단 축소안을 검토한 뒤 차량 상부를 제외할 우려가 있어 원본 박스를 유지했다.

## 보류·검사 결과

ID19 왼쪽 가장자리에는 표시되지 않은 사람 다리가 보인다. ID77의 선반 사이 작은 녹색 배경 인물 가능성, ID14의 배경 인물/걸린 옷 구분이 불확실해 이 세 전체 화면과 관련 크롭은 제외했다. 나머지 미승인 후보는 pending 상태다.

모든134장 디코딩, 이미지·라벨 목록 일치, 클래스·좌표·유한값 검사 통과. 기존 val/test 이미지와 라벨은 바이트가 동일하며 현장/원본 영상 그룹의 분할 간 중복이 없다. 정확히 같은 디코딩 픽셀 이미지 중복은0개다. 비슷한 장면·인접 프레임을 전수 판정한 검사는 아니다. 추가19원본 그룹은 현재111장 구성에서 미사용 그룹이지만 같은 현장일 수 있다. 시연 영상은 추가하지 않았다.

## 상태·재현

prepared_not_trained. 데이터 증가가 실제 감지 개선을 보장하지 않으며 같은 시험·영상에서 재학습 결과를 비교해야 한다. 다음 실험은 v6를 초기값으로 낮은 bias warmup 설정을 유지해 데이터 보완 효과를 확인할 예정이다. 최종 발표 모델은 아직 미확정이다.

safety 환경에서 scripts/select_error_focus_candidates.py로 후보 생성, scripts/prepare_hard_examples.py --config configs/review/error-focus-v1.json으로 구성한다. 기존 출력 덮어쓰기를 차단하므로 재현은 별도 출력 또는 새 체크아웃에서 수행한다. 검수 승인·보류·교정은 configs/review/error-focus-v1.json, 데이터 QA는 docs/checkpoints/2026-10-06/error_focus_v1_qa.json에 기록했다.

데이터·라벨은 로컬 및 같은 디스크의 SHA256 검증 복구 사본으로 보관하며, 원본 ZIP도 유지했다. 구성 코드와 검수 기록은 GitHub 작업 브랜치로 업로드한다. 원본·생성 데이터는 현재 Git 제외 정책에 따라 로컬 보관하고 main 병합은 별도다.
