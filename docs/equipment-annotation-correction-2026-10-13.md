# 사용자 확정 설비 오라벨 수정

2026-10-13 사용자가4번 영상 왼쪽 짙은 파란 구조물은 기계이며 오른쪽은 실제 작업자라고 확정했다. 앞선 확대사진에서 사람처럼 보인 부분도 사용자의 대상 확인으로 기계 라벨 제거 대상으로 확정했다.

프로젝트 data의 YOLO 이미지/라벨 연결을 검색했다. reviewed_pilot의 평면 images 경로12,311개 및 추가 구조/다른 data 경로4,697개, 총17,008개 이미지 파일 경로를 해시로 묶고4번 카메라 배경과 특징점/호모그래피로 대조했다. 중복 경로는 독립사진 수가 아니다. 정렬되는 사진에서 확인된 기계 위치의 사람/머리 박스만 제거했다. 오른쪽 작업자와 다른 라벨은 원래 문자열 그대로 유지했으며 수정95개 파일의 나머지 라벨과 원래 이미지SHA를 검증했다. 이미지 삭제0, 빈 라벨로 바뀐 파일0. 복구본은 outputs/checkpoints/equipment_annotation_correction_2026-10-13/originals에 보관하며 학습 대상으로 사용하지 않는다.

- 최종 PPE ppe_final_510:19항목/19개 머리 박스 제거. 학습510항목 유지, 착용467박스·미착용544박스, 총1,011박스. 수정 전1,030박스 수치는 과거 기록이다.
- cvat_helmet_merged 및 cvat_helmet_training_v1/v2:각12개 라벨 수정. 일부 예전 검증/시험 라벨도 잘못된 정답을 수정했으므로 그 데이터로 계산한 과거 수치는 재평가가 필요하다.
- logistics_demo_adaptation_v1:16개 사람 라벨 수정.
- logistics_v7_full_scene/v9_hard_examples/error_focus_v1/multisite_v1:각6개 사람 라벨 수정.
- demo-adaptation-v1 원천 설정4개 박스와 prepare_full_scene_expansion의6개 원천 박스, 해당 현재 manifest/현재 라벨SHA를 수정했다. 반복 생성해도 같은 설비 정답이 다시 들어가지 않도록 원천 생성 설정을 고쳤다.

기존 모델 파일은 바꾸거나 삭제하지 않았다. 라벨 수정은 이미 학습한 가중치를 수정하는 작업이 아니다. configs/ppe-final-model.json 및 demo-object-model.json에 training_annotations_corrected_model_weights_not_retrained와 과거 평가의 수정 전 상태를 표시했다. 수정 데이터로 새 모델을 학습·비교하고 채택하기 전에는 전체 현장 일반화 개선이나 가중치 수정 완료로 주장하지 않는다. COCO 사전학습 모델의 설비 오탐이 이 프로젝트 오라벨에서 비롯됐다고 단정할 수 없다.

현재4번 고정 카메라에서는 사용자 확인 설비 범위의 사람/머리 후보만 판정 입력에서 제외한다. 확인 영역 밖의 오른쪽 실제 작업자는 유지하며 머리 후보도 추적/PPE판정 전에 제외한다. 이는 사용자 확인 기반 카메라 설정으로, 새 현장에 일반 적용하는 모델 개선이 아니다. 원본 검출과 제외 이유는 진단 기록으로 남긴다. 중앙 통로 ROI와 거리/체류규칙은 변경하지 않았다. 다른 설비 지게차 오탐, 앉은 작업자 초기미탐, ROI 미확인 색 표시 등의4번 앞선 리뷰 항목은 별도의 후속 보완 대상이다.

원래 영상/평가 기록은 수정 전 결과로 보존한다. 최신 설비 보완 리뷰 영상은 outputs/diagnostics/video4_equipment_corrected_v6/video4/demo.mp4이며 과거 리뷰 영상과 구분한다. 자동 테스트182개 통과. 관련8항목 체크리스트 중2/3/4/6/8의 데이터/규칙 정정과 검증 근거에 기여한다.
