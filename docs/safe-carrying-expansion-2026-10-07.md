# 추가 지게차 train 영상 검수·교정 학습

## 기존 사용 내역과 부족했던 점

두 train 폴더의 MP4 70개(과적 운반 48개, 안전 운반 22개)는 기존에도 발견했다. 과거 관련 영상 준비 기록에는 195개 후보 중 검수한 15개 크롭을 v16에 반영한 것으로 남아 있다. 70개 영상을 모두 충분히 라벨링해 학습했다고 볼 수 없으며, 정면·적재·가림 장면 보완이 부족했다.

이번에는 70개 영상에서 25%·65% 시점 140개 프레임을 추출하고 12개 미리보기 시트로 검수했다. 모든 동영상 전체를 재생 검수했다는 의미는 아니다.

## 라벨 교정 및 학습

첫 실험의 운전석·본체 중심 89개 라벨은 적재 차량 전체 박스와 범위가 달랐다. 8 epoch 실험과 가중치는 보존하지만 기본 모델로 채택하지 않는다. epoch3의 후진 영상 전체 527개 프레임 비교에서 신뢰도 0.25 이상 지게차 제안이 있는 프레임은 기존 428개, 새 단독 175개, 보완 결합 428개로 연속성 개선이 없었다. 이는 객체의 정답 대비 미탐 수와 다른 지표다.

교정 라벨은 지붕·운전석·차체·포크 등 차량 부품이 식별되는 적재 차량을 운반 적재물까지 포함하는 박스로 표시한다. 독립된 상자를 지게차로 라벨링하지 않는다. 107개 프레임을 승인했고 식별이 모호한 33개는 보류했다. 보류 프레임은 음성 이미지로 넣지 않는다. 승인된 박스 미리보기 8장을 확인했다.

기존 replay와 Nvidia 검수 자료를 포함해 train729/val88/test50, 단일 클래스 forklift를 구성했다. 기존 group 분리를 유지했으나 같은 현장의 원본 클립 사이 중복 사건 가능성과 이전 시연 학습 노출 때문에 독립 새 현장 평가로 해석하지 않는다.

교정 학습: 기존 demo_object_adaptation_v1/best.pt에서 2 epoch, AdamW lr0.0002, freeze6, imgsz640. 새 지게차 클래스는 모델의 클래스 이름으로 전달되며 person/PPE 모델을 바꾸지 않는다.

## 검증 기준

- 기존 후진 12.4~13.8초의 8개 수동 정답 박스 및 IoU0.5 기준 유지.
- test50에서 모델 이름으로 클래스 매핑, 기존40/추가 공장8/Nvidia2를 별도로 보고.
- 후진 영상은 원본25fps의 527개 프레임 모두 실제 추론. 제안 존재 수를 미탐0으로 표현하지 않음.
- 사람이 보이지 않거나 차량이 가려져 확인 불가하면 안전으로 단정하지 않음.
- 이전의 신뢰도0.25 이상 검출을 보호하는 보완 결합 방식도 평가. 중복 박스·오탐 증가는 별도로 기록.
