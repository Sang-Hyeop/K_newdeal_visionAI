# 4기능 마무리 점검

통로 규칙 최신 사용자 기준 수정: 4·7번 차량 관측 시 즉시 주의, 관측 체류 3초 이상 위험. 무차량 관측 시 3초 미만 정상, 이후 최대 주의. ROI 좌표 그대로 유지. 일반 체류 분류 임계값과 조건부 차량 위험 임계값 분리. 여러 작업자 및 2.99/3/3.01초 경계 자동 검사 추가. 전체 단위 검사 149개 통과. 실제 영상 신규 검증 완료로 해석하지 않음.

현재 남은 작업:
- PPE: v6 최종 단독 감지 모듈 제공 완료. 기존 통합 시연은 과거 앙상블 경로라 아직 교체/영상 비교 필요. 보관된 config만 바꿔 완료라고 하지 않는다.
- 사람–지게차 위험 접근: 추적/거리 규칙 구현 및 단위 검사 확인. 화면상 사람 높이 정규화 거리, 미터 아님. 가림·후진 차량 미탐 및 ID 유지 실영상 확인 필요.
- ROI 침범·체류: 4·7번 시간 기준 최신화, 좌표 변경 없음. 카메라별 영역 적합성과 복수 작업자 장면 실영상 검증 필요. 사진/과거 결과는 규칙 수정 후 자동 갱신되지 않음.
- 결과 저장: 공통 이벤트와 관측 JSONL 구현 및 단위 검사 확인. 실제 팀 백엔드/관제 화면까지 연동 완료 여부는 이 점검에서 확인되지 않음.
- 지게차: 기존 데이터/평가 기록 점검 완료. 새 140장 라벨링 및 클래스 매핑, 원천별 분리 후 후보 학습/비교 예정. 사람 누락 라벨을 두 클래스 학습에 그대로 혼합하지 않음.

추가 학습 및 배포 모델 변경 없음. 전체 프로젝트 완료 또는 독립 현장 정확도로 주장하지 않음. 우선 순위: 최종 PPE 통합 연결, 최신 규칙으로 4·7 영상 재검증 및 저장 계약 확인, 새 지게차 라벨 검수/학습.
