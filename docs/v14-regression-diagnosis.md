# v14 퇴행 진단 기록

추가 학습을 반복하기 전에 모델 전달·누락 유형·학습 분포·입력 설정을 점검했다. 이번 단계는 진단이며 새 모델 학습이나 운영 설정 변경은 없다.

## 초기 모델 전달

설치된 Ultralytics8.4.153의 DetectionTrainer.get_model을 사용해 v6와 같은 두 클래스 모델을 재구성했다. 가중치·버퍼708개 모두 원본과 동일, person/forklift 클래스 순서도 동일했다. 초기 가중치 전달이 잘못되었다는 증거는 없다. 이 검사는 학습 전 초기화만 검증하며 이후 업데이트의 적절성을 증명하지 않는다.

## 누락 유형

기존시험11장에 v6/v12/v14를 conf0.05까지 추론하고, conf0.25/IoU0.5에서 일대일 정답 매칭을 재현했다. 세 모델 모두 이전 TP/FP/FN과 일치했다. v14 사람FN9 중5개는 IoU0.5 이상인 같은 클래스 후보가0.25 미만 신뢰도로 남아 있었다. 나머지4개는 conf0.05 이상 후보에서 맞는 박스가 없었다. 지게차FN3 중2개는 낮은 신뢰도,1개는 박스 범위 불일치(최고 IoU0.472)였다. 후보 존재 여부는 원인을 확정하는 설명이 아니다.

누락이 있는 대표5장을 원본 정답 오버레이와 대조했다. 작은/차량에 가려진 사람과 운전자, 적재 지게차의 범위 불일치가 보인다. 이 표본에서 명백한 정답 오류를 확정하지 못했고 라벨을 바꾸지 않았다. 모델 예측을 정답으로 채택하지 않았다. 사람FN9 중8개는640 입력 기준 높이가48픽셀 미만이지만 표본이 작아 크기를 유일한 원인으로 단정할 수 없다.

## 학습 분포

train115장, 사람151개·지게차78개·배경11장. 사람 높이는640 입력에서32픽셀 미만28개,32~64미만64개,64이상59개다. 92/151개가64픽셀 미만이다. 사람박스78개는 지게차박스 안에 면적80% 이상 포함된다. 이는 운전자/차량 가림 표본 비중의 점검용 기하학 지표이며 운전자78명이라는 검증 결과가 아니다. 전체 사람 라벨을 역할별 수동 분류한 것은 아니다. 같은 원본 그룹에서 나온 크롭과 영상 프레임이 있어115장이115개 독립 현장/영상을 의미하지 않는다.

## 검증8장의 설정 비교

v6/v12/v14 × 입력640/960 × conf0.25/0.1의12개 조건을 val8장에서 비교했다. 정답 사람10개·지게차8개, IoU0.5 유지. test로 임계값을 선택하지 않았다.

v14의640/conf0.25는 사람TP5/FP3/FN5, 지게차TP8/FP1/FN0이다. conf0.1로 낮추면 사람TP5/FP11/FN5라 누락은 그대로이고 오탐만 늘어난다.960/conf0.25는 사람TP4/FP3/FN6으로 오히려 누락이 늘었다.960/conf0.1은 사람TP6/FP12/FN4, 지게차TP8/FP5/FN0으로 누락 감소 대신 오탐이 늘었다.

v12의960/conf0.1은 사람TP7/FP14/FN3, 지게차TP8/FP4/FN0으로 역시 오탐 증가가 크다. 해상도 확대나 신뢰도 하향을 보편적인 해결책으로 채택할 근거가 부족하다. 기존 운영 입력·임계값·모델은 유지한다. 이8장은 학습 중에도 반복 사용한 소표본이며 최종 독립 검증이 아니다. 같은 val에서 v14가 좋아 보여도 test/영상에서 퇴행할 수 있으므로 val 수치만으로 승격하지 않는다.

## 코드와 검증

audit_pilot_predictions.py에 split/입력크기/신뢰도/가중치 선택 옵션을 추가했다. 기존 기본 설정의 결과가 v14 이전11장 보고서와 같음을 확인했고 잘못된 입력크기641을 거절하는 실행 검사와 코드 컴파일을 통과했다. diagnose_detector_regression.py는 가중치 전달 검사·오류 비교·학습분포 진단을, compare_validation_input_settings.py는12개 검증 조건을 재현한다. 기존 출력이 있으면 보호하며 모델·라벨을 수정하지 않는다.

## 다음 작업과 저장

이번 점검으로 단일 원인을 확정하지는 못했다. 소량을 추가해 짧게 학습하는 반복에 앞서, 원본 영상/현장 단위로 더 큰 검수 묶음을 구성하고 작은 보행자·운전자·차량 가림·적재 지게차·설비 배경의 균형과 일관된 보이는 범위 라벨을 확인해야 한다. 검증 자료도 기존8장/11장에만 의존하지 않도록 별도 현장 그룹에서 확대 검수해야 한다. 최종 시연 영상은 학습 제외를 유지한다.

진단 JSON과 대표 이미지는 같은 디스크의 SHA256 검증 복구 사본으로 보관한다. 코드·진단 기록은 기존 GitHub 작업 브랜치에 업로드하며 main 병합은 별도다. 새 학습모델은 생성하지 않았다.
