# 팀 공용 시연 영상

시연·개발 점검용 MP4 7개를 Git으로 공유한다. 현재 파일의 SHA-256, 크기, 길이는 configs/demo-videos.json에 기록했다. 학습에는 사용하지 않는다. 이 폴더 이외의 학습 이미지, ZIP, 모델 가중치와 생성 결과는 별도 공유한다.

작업 브랜치는 chore/detection-data-checkpoint다. 해당 브랜치를 clone하거나 기존 저장소에서 fetch 후 선택하면 영상도 내려받는다. main에는 병합 전까지 포함되지 않는다. 7개 영상 총 용량은 약 219 MiB이며 최대 파일은 약 51.5 MiB다. Git LFS 없이 일반 Git으로 저장했다.

1_forklift_forward.mp4는 이전 등록본(576프레임)과 다르며 현재 파일은 526프레임, 약 21.94초다. 이전 등록 해시도 configs에 남겼다. 과거 결과와 비교할 때 파일 버전을 확인한다. 나머지 6개 영상의 해시는 이전 등록과 동일하다.
