# 팀 공용 시연 영상

시연·개발 점검용 MP4 7개를 Git으로 공유한다. 현재 파일의 SHA-256, 크기, 길이는 configs/demo-videos.json에 기록했다. 학습에는 사용하지 않는다. 이 폴더 이외의 학습 이미지, ZIP, 모델 가중치와 생성 결과는 별도 공유한다.

작업 브랜치에서 fetch 후 선택하면 영상도 내려받는다. main에는 병합 전까지 포함되지 않을 수 있다. Git LFS 없이 일반 Git으로 저장했다. 최신 SHA·크기·길이는 configs/demo-videos.json을 본다.

1_forklift_forward.mp4는 이전 등록본(576프레임)과 다르며 현재 파일은 526프레임, 약 21.94초다. 7_Logistics Warehouse.mp4는 약 4:32에서 약 3:01로 줄인 뒤 x264로 재압축했다(약 21 MiB). 과거 결과와 비교할 때 파일 버전·해시를 확인한다.
