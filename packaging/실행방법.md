# 시선 안전관제 — 실행 방법 (Mac / Windows 1페이지)

지금 대시보드를 그대로 **아이콘 더블클릭**으로 엽니다. 터미널에 `python team7.py`를 칠 필요는 없습니다. 창을 닫으면 앱(서버)도 같이 끝납니다.

## 필요 환경 (한 대에 한 번)

| 항목 | 내용 |
|------|------|
| Python | 3.10 이상 (`python --version`) |
| 패키지 | `pip install gradio pandas` |
| 브라우저 | Chrome 또는 Edge (앱 창 모드) |
| 데이터 | GitHub `K_newdeal_visionAI` main, 발표 영상 1~5 (`handoff.py`, `data/videos`) |
| 계정 | 아이디 `qwer1` 또는 `qwer2` / 비밀번호 `1234` |

데이터 폴더가 `c:\code\K_newdeal_visionAI_main` 이 아니면, 실행 전에 `SISUN_DATA=그경로` 를 지정합니다.

## Windows

1. `safety test` 폴더를 압축 해제합니다. (`sisun.vbs`, `team7_desktop.py`, `team7_app`이 같이 있어야 합니다)
2. `packaging\windows\make_shortcut.ps1` 을 우클릭 → **PowerShell로 실행** 하면 바탕화면에 **Sisun** 아이콘이 생깁니다.
3. 또는 폴더 안의 **sisun.vbs** (한글 이름 **시선.vbs** 도 같음) 를 더블클릭합니다.
4. 로그인 화면이 뜨면 아이디·비밀번호를 넣습니다.
5. 창의 **X** 를 누르면 관제도 종료됩니다.

검은 콘솔이 보이면 `시선.bat` 대신 `sisun.vbs` 를 쓰세요.

## macOS

1. `safety test` 폴더를 통째로 복사합니다.
2. 터미널에서 한 번만: `chmod +x "시선.app/Contents/MacOS/sisun"`
3. **시선.app** 을 더블클릭합니다. (막히면 우클릭 → 열기)
4. 로그인 후 사용하고, 빨간 버튼을 누르면 종료됩니다.

`packaging/macos/시선.app` 도 같은 프로그램입니다. `team7_desktop.py` 가 있는 폴더와 함께 두면 됩니다.

## 확인 체크리스트

- [ ] Python 3.10+ / Chrome 또는 Edge 설치됨
- [ ] 발표 영상 1~5 데이터 저장소가 보임
- [ ] 아이콘(또는 `sisun.vbs` / `시선.app`) 더블클릭
- [ ] 로그인 화면이 브라우저 탭이 아니라 **앱 창**으로 뜸
- [ ] `qwer1` / `1234` 로 로그인되면 관제 탭이 보임
- [ ] 창을 닫으면 다시 더블클릭해야 열림 (백그라운드에 안 남음)

문제가 있으면 `safety test/team7_data/desktop.log` 를 봅니다.
