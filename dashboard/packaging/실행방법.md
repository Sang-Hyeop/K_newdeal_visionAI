# 시선 설치와 실행

## Windows

1. GitHub에서 최신 코드 ZIP을 받고 새 폴더에 **전체 압축 해제**합니다.
2. **시선_설치.cmd**를 더블클릭하고 설치 완료까지 기다립니다. 기존 Windows용_시선설치.vbs도 동일합니다.
3. 바탕화면 **시선**을 더블클릭합니다.

Windows 10/11 x64, 인터넷, Edge 또는 Chrome이 필요합니다. Python 수동 설치는 필요하지 않습니다. 첫 설치는 Python·라이브러리·모델·최신 리뷰 자료를 다운로드하므로 시간이 걸립니다. 프로젝트 전용 `.sisun/venv`를 사용합니다. 폴더를 옮기면 설치 파일을 다시 실행해 바로가기를 갱신합니다.

시선 창을 닫으면 해당 실행의 서버와 API가 종료됩니다. 실행 중 다시 클릭하면 창을 다시 열고, 응답 없는 오래된 동일 프로젝트 실행만 복구합니다. 잠금 파일을 직접 삭제하거나 다른 Python을 모두 종료하지 않습니다.

설치 오류: `.sisun/install.log` · 실행 오류: `dashboard/data/desktop.log`

## macOS

기존 safety 환경과 실행 자료를 설치한 뒤 `macOS용_시선설치.command`로 바탕화면 시선.app을 만듭니다. macOS 실행 방식은 변경하지 않았습니다. 자세한 수동 설치는 `docs/github-team-quickstart.md`를 참고합니다.

로그인 예: 김상협 / 1234
