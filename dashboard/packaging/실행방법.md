# 시선 — 다른 PC에서도 동일하게

프로젝트 폴더(또는 GitHub ZIP)만 있으면 됩니다.  
설치 파일이 **내 PC 경로를 하드코딩하지 않고**, 지금 풀린 폴더 기준으로 동작합니다.

## 필요 환경 (각 PC에 한 번)

- Python 3.10+ (권장: Anaconda `safety` 환경)
- `pip install gradio pandas` (+ `requirements-runtime.txt` 감지용)
- Chrome 또는 Edge
- 발표 영상 1~5 데이터

## 설치 → 실행

### macOS

1. 프로젝트 루트에서 **`macOS용_시선설치.command`** 더블클릭  
2. 바탕화면에 **`시선.app`** 생성 (AppleScript 앱 · 더블클릭 실행용)  
3. 바탕화면 **시선.app** 더블클릭 (처음 막히면 우클릭 → 열기)  
4. 프로젝트 폴더를 옮겼으면 설치를 한 번 더 실행

### Windows

1. 프로젝트 루트에서 **`Windows용_시선설치.vbs`** 더블클릭  
2. 바탕화면에 **시선** 바로가기 생성  
3. 바탕화면 **시선** 더블클릭

로그인 예: `김상협` / `1234`

## 구조

| 구분 | 역할 |
|------|------|
| `macOS용_시선설치.command` / `Windows용_시선설치.vbs` | 한 번만 — 바탕화면 바로가기 |
| `dashboard/packaging/macos/시선.app` | Mac 실제 앱 |
| `시선.vbs` | Windows 실제 실행 (바로가기가 가리킴) |
| `dashboard_desktop.py` | 공통 Python 진입점 |

문제 로그: `dashboard/data/desktop.log`
